# 学習後画像のサーバー差し替え

この機能を含むアプリを最初に1回ビルド・配信する必要がある。
導入後は、以下の画像更新でiOS/Androidのビルドは不要。

## 更新手順

1. 昼と夜の画像を1つのフォルダに用意する。PNG/JPEG、各1〜10枚。
   ファイル名は `昼_01_紅葉.png` / `夜_01_月見.png` または `day_01.jpg` / `night_01.jpg`。
   各画像5MB以下・縦横4096px以下、合計30MB以下。
2. リポジトリ直下で実行する。

   ```powershell
   node --import tsx tools/publish_afterstudy.mjs --source "画像\アプリ画像\季節_秋\学習後"
   ```

3. `web/afterstudy/manifest.json` と `web/afterstudy/images/` の追加画像を確認し、コミットしてmainへpushする。
   Pages配信ワークフローが `/afterstudy/` をGitHub PagesとCloudflare R2へ配信する。
   アプリのビルドワークフローを手動起動する必要はない。

初期の配信データは同梱の秋JPEGから生成済み。
引数なしで生成器を実行すると、この同梱秋画像の一覧へ戻せる。
以前のmanifestを戻してpushすることでもロールバックできる。
サーバー上の古いハッシュ付き画像は、古い一覧を持つ端末のために残しておく。

## アプリの動き

- 起動時と前面復帰時に確認（同一プロセス内では5分間隔）。画面の起動を待たせない。
- `https://jlpt.safa-lang.com/afterstudy/manifest.json` の昼夜別一覧を使う。
- 同名でも内容が変わればハッシュ付きファイル名が変わり、差分だけ再取得。
- サイズとMD5を検証し、全画像を端末へ保存できた時だけ一覧を切り替える。
- オフライン・破損・タイムアウト時は保存済み一覧を維持。初回は同梱画像。
- 表示時の読み込みエラーでも同梱画像へ戻る。結果画面の表示途中では絵を切り替えない。
- 端末には現在と直前の一覧の画像を保持し、それより古いものを削除する。
- Web版は同梱画像を使う。ネイティブアプリが端末への保存対象。
