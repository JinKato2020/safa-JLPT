# ステータスパネル 再現(方式B) 設計

作成 2026-07-13 / ユーザー選択: B（HOME.png背景＋独立パネル素材を新規生成し、参考=ホームタブ2.png に寄せる／1px完全一致は不可＝"近い"）

## 目的
ホーム中央のステータスパネルを、参考画像（`画像/アプリ画像/ホームタブ2.png` のRPGステータス）に**限りなく近い見た目**で再現する。
背景は HOME.png のまま。パネルは**独立素材（枠）＋コード描画（バー/数値）**のレイヤー構成で、色・寸法・位置は参考を**実測した値**に合わせる。

## 実測した参考仕様（色）
- 枠（木目）: 濃茶 `#50382E`／淡木・縁 `#B79579`／金装飾 `#c8a24e`〜`#e7c877`
- 区分バー（紫グラデ・段目盛り）: 明 `#EDE6FF` → 中 `#824EBD` → 深 `#47387D`（左→右で暗くなる）。トラック=暗色。
- 合格到達度バー（虹グラデ）: シアン `#66B0D7` → 金 `#F6C569` → 紫 `#824EBD`
- 文字: クリーム/金 `#f3e6cf`〜`#ffe6a3`
- 稲妻: 青白（芯=白 `#ffffff`／周辺=青 `#7fb8ff`）
- 左に縦「ステータス」木札（クリーム地・茶字）。ヘッダー左に円形の巫女ポートレート（金の魔法陣リング）。

## レイヤー構成
```
Layer3  稲妻(GPUシェーダ・expo-gl・青白・バー上を striking)   ← 動作確認済(1408)
Layer2  ヘッダー/合格到達度/5区分バー(コード描画・実測色・数値カウントアップ)
Layer1  (バーの溝＝Layer0枠の内側に配置)
Layer0  枠素材(濃茶木目＋金装飾＋ステータス札＋巫女ポートレート枠。生成・透過)
```

## Layer0: 枠素材（Nano Banana 生成 → 透過処理）
- 生成: **濃茶木目のRPGパネル枠**（参考同様の角の金装飾＋蔓草＋左の縦ステータス木札＋左上に円形ポートレート枠(金の細い魔法陣リング)）。**内側は空**（バー/文字は載せない）。背景は単色（chroma-keyで透過に）。
- アスペクト: 参考パネル比（実測 約 535:540 ≒ ほぼ正方形〜わずかに縦）。`STATUS_FRAME_ASPECT` を実測で確定。
- 透過: 生成物の外側単色を chroma-key（既存 electric と同手法）で透明化 → HOME.png の上に馴染む。
- サイズ: コンパクト（`cardW = min(width*0.78, 320)`）＝背景を活かす。

## Layer2: コード描画（実測色・位置）
枠素材の内側に、実測位置(枠内の割合)で配置：
- **ヘッダー**: 円形ポートレート（枠側の魔法陣リング内に `GUIDE.open`）＋右に3行 `ランク：{称号}` / `継続日数：{n}日` / `桜貝：{points}`（※参考の「学習ポイント」を内部通貨=桜貝に読み替え）。文字色クリーム/金。
- **合格到達度バー**: 虹グラデ（`#66B0D7`→`#F6C569`→`#824EBD`）、丸端、`合格到達度 {pass}%` ラベル＋右端 `100%`。実データ `passPct` で伸びる。
- **5区分バー**（漢字/語彙/文法/読解/聴解）: 参考の**紫グラデ段目盛り**（`#EDE6FF`→`#824EBD`→`#47387D`）＋暗トラック。左=区分名(明朝)、右=`{pct}%`。実データで伸び＋カウントアップ。
  - ※参考は色を区分で分けず**全て紫**。区別はラベルで（色は統一紫）。
- 段目盛り(タリー)・丸端・内側ハイライトを参考に合わせる。

## Layer3: 稲妻（既存 ElectricShader 流用・調整）
- 1408 で GLView 描画は動作確認済。青白ギザギザの striking をバー領域に重ねる（加算合成）。参考同様、左側とバー上で強め。強度/本数/色は uniform 調整。

## データ源（既存 homeStatus）
- `passPct`=readiness.passProbability、5区分=各正解率、`streakDays`=streak.current、`points`=wallet.points（ポイント機能実装後。未実装なら 0 or 学習時間で暫定）、`rankTitleKey`=tier称号。

## 実装ファイル
- 生成/配置: `app/assets/tabs/status_frame.png`（濃茶木目枠に差し替え）＋ `STATUS_FRAME_ASPECT` を実測更新（`FramedPanel.tsx`）。
- `FramedPanel.tsx`: 枠＋内側パディングを実測比に更新。
- `StatusPanel.tsx`: ヘッダー/合格到達度/5区分バーを実測色・位置で描画（紫統一・虹メインバー）。
- `ElectricShader.tsx`: 青白 striking（調整のみ）。
- HomeScreen: `cardW` コンパクト（済）。

## 段取り
1. 枠素材を生成（濃茶木目・空内側）→ chroma-key 透過 → サンプル提示・承認。
2. `STATUS_FRAME_ASPECT`・内側パディングを実測確定。
3. StatusPanel をコード描画で実測再現（紫バー・虹メインバー・ヘッダー）。
4. 稲妻を参考トーンに調整。
5. 実機で参考と並べて微調整（位置/サイズ/色を1pxずつ寄せる）。tsc/test/ビルド。

## 限界（正直に）
- painted の枠はAI再生成のため参考と**完全一致(1px)は不可**＝"非常に近い"止まり。バー/数値/稲妻はコード制御で実測色・位置に合わせ込む。
- 完全一致が必須なら方式A（参考シーンを背景に敷く）が唯一。Bは"近似の最大化"。

## 検証
- tsc緑・既存テスト維持。実機で参考画像と重ね、位置/サイズ/色の差を詰める。ビルド番号併記。
