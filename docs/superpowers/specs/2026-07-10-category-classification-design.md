# 設計: 漢字・語彙・文法のカテゴリー分類（全レベル共通・単語タブ再構成）

- 日付: 2026-07-10
- 対象: まいにちJLPT（safa-JLPT）単語タブ
- 目的: 50音順の辞書的リストをやめ、**種類ごとに最適な軸でテーマ分類**し、飽きず意味のつながりで覚えられる学習リストにする。カテゴリー枠は**全レベル(N5/N4/N3)共通**（中身＝どの項目がそのレベルに出るかはレベル別のまま）。

## 決定事項（ユーザー承認済 2026-07-10）
- 分類の枠はレベル横断で共通（per-levelで分類法は変えない）。
- 漢字・語彙は**同じ8大分類の“傘”**で視覚的に一貫。語彙は各傘の下に**小テーマ2階層**。
- 文法は意味テーマに乗らないので**機能別の専用体系**。
- 非自立語(～)のうち**文法にもある24語は語彙から外し文法へ**、**文法に無い助数詞50語は語彙に残し「助数詞（数え方）」小テーマ**にする。
- 漢数字(一〜十)の例単語に**数え方**（数/日/つ/個）を含める。

---

## 1. 漢字: 意味の8大分類（承認済）
`id` / 日本語ラベル / 例:
1. `nature` 自然・天地 — 日月火水木土山川雨天空海風雪星
2. `position` 位置・方向 — 上下左右中外前後内間東西南北
3. `body` 人・体・家族 — 人男女子父母兄姉目耳口手足体心血
4. `numtime` 数・時・暦 — 一〜十百千万半／年月週日時分今毎午
5. `action` 動作（動詞） — 行来出入見聞言話読書食飲買売作使立歩
6. `state` 様子・性質（形容詞） — 大小多少長短高安新古明暗強弱白赤青黒
7. `society` 暮らし・社会 — 学校会社店駅道町村国市家事仕金円銀業
8. `mind` 心・考え・抽象 — 心思知意味理問題答感愛楽悲不非

各漢字は必ず1つに属する。漏れは意味上最も近い傘へ（「その他」は作らず必ず8のどれかに寄せる）。

## 2. 語彙: 8大傘 × 小テーマ（2階層）
傘は漢字と同一8。各傘の下に小テーマ（`sub` id）。1塊が10〜15語になる粒度。全語彙は必ず1小テーマに属す。

- `nature` 自然・天地: `weather`天気・季節 / `animal`動物 / `plant`植物 / `geo`地理・自然
- `position` 位置・方向: `direction`位置・方向 / `deixis`指示(こそあど場所)
- `body` 人・体・家族: `family`家族・人 / `bodyhealth`体・健康 / `relation`人間関係・呼び方
- `numtime` 数・時・暦: `number`数・量 / `time`時間・日付 / `counter`助数詞（数え方）
- `action` 動作（動詞）: `move`移動・往来 / `giveget`授受・売買 / `perceive`見る聞く話す / `daily`日常動作 / `mindverb`心の動き(動詞)
- `state` 様子・性質: `size`大小・多少・長短 / `quality`新旧・良悪 / `color`色 / `sense`感覚・様子 / `adverb`副詞
- `society` 暮らし・社会: `food`食べ物・飲み物 / `home`家・日用品 / `clothes`衣服 / `shopmoney`買い物・お金 / `transport`交通 / `place`場所・建物 / `school`学校・勉強 / `work`仕事・社会 / `hobby`趣味・遊び
- `mind` 心・考え・抽象: `emotion`気持ち・感情 / `think`思考・判断 / `abstract`抽象概念 / `expression`あいさつ・表現 / `function`機能語(こそあど等)

`counter`（助数詞）に、文法に無い～50語（～円/～個/～枚/～本/～匹/～杯/～台/～冊/～人/～歳/～時間/～日 等）を配置。

## 3. 文法: 機能別（専用体系・全レベル共通）
`id` / ラベル:
1. `particle` 助詞（は・が・を・に・で・と・から・まで・へ・の・も）
2. `verbform` 動詞・活用の形（て・た・ない・可能・受身・使役・意向・命令）
3. `pattern` 文型・接続（〜たり・〜ながら・〜し・〜たり）
4. `timeorder` 時・順序（〜とき・〜まえに・〜あとで・〜あいだ）
5. `reason` 理由・目的（〜から・〜ので・〜ために・〜ように）
6. `condition` 条件・仮定（〜ば・〜たら・〜なら・〜と）
7. `request` 依頼・許可・禁止・意志（〜てください・〜てもいい・〜てはいけない・〜ましょう）
8. `degree` 比較・程度（〜より・〜ほど・〜くらい・〜すぎる）
9. `evidential` 推量・伝聞・様態（〜そうだ・〜ようだ・〜らしい・〜だろう）
10. `suffix` 接尾・機能語（〜中・〜すぎ・〜がる・〜やすい・お〜／文法にある24語の～はここ）
11. `keigo` 敬語・丁寧（お〜・ご〜・〜ございます）

各文法点は1機能に属す。

## 4. データモデル
- `src/data/categories.ts`（正本タクソノミー）: 傘8・語彙小テーマ・文法機能を、`{ id, jaLabel, umbrella?, order, icon? }` で定義。i18nキー `cat.<id>` を持つ（ラベルは i18n 化。初期は ja/en、他9言語は後続の翻訳パスで機械訳→精査。既存の多言語運用に準拠）。
- 割当データ（id→category）:
  - `src/data/kanjiCategory.json`: `{ "日": "nature", ... }`（char→傘id・612件）
  - `src/data/vocabCategory.json`: `{ "n5-v-1": "family", ... }`（vocab id→小テーマid・全語）
  - `src/data/grammarCategory.json`: `{ "n5-g-1": "verbform", ... }`（grammar id→機能id・全点）
- 未割当が出た場合はビルド前チェックで検出（`node`走査）し、必ず0件にする（全項目1カテゴリ）。

## 5. 割当方法（プラン側で詳細化）
- 漢字612・文法393は件数が少なく**キーワード規則(意味/point)＋全件レビュー**で確定（純Python生成→人手補正）。
- 語彙3526は**キーワード規則(意味L1/読み/品詞)で一次割当→曖昧語のみ少数の大きめSonnetエージェントで確定**（エージェント乱発しない＝束ねて数個）。生成物は id→sub の JSON。
- 文法にある24語の～vocabは `vocabCategory` から除外＋`grammarCategory`へ（該当grammar点に紐付け）。実質は**語彙リストから非表示**（データ削除ではなく分類上grammar側へ）。

## 6. 漢数字の数え方（例単語追加）
- 対象: 一二三四五六七八九十（＋百千万半は数のみ）。各数字漢字の例単語に:
  - 数: いち/に/さん/よん/ご/ろく/なな/はち/きゅう/じゅう
  - 日: ついたち/ふつか/みっか/よっか/いつか/むいか/なのか/ようか/ここのか/とおか（＋十四=じゅうよっか, 二十=はつか, 二十四=にじゅうよっか は該当字の例に）
  - つ(抽象): ひとつ/ふたつ/…/とお
  - 個(小さい物理): いっこ/にこ/…/じゅっこ
- 例単語データ（`kanjiCardReadings`／`kanjiExamples`）に追記。表示は詳細カード。
- 音声: 既存mp3を再利用。未生成の読みのみ**かな送信で生成**（Neural2-B・正確な読み）。ドリル代表(`kanjiDrillReps`)の数字は「数」読み（五→ご 等・四=よん維持）。

## 7. UI（単語タブ）
- 現状: `BrowseScreen`(mode='study') が `levelListFor(kubun, level)` を平坦表示。
- 変更: カテゴリー見出し付き**セクションリスト**（`SectionList`）で表示。セクション順＝タクソノミー`order`。
  - 漢字: 8傘のセクション。
  - 語彙: 8傘を大見出し、小テーマを小見出し（2階層。実装は傘ごとにグルーピングし小テーマ副見出し）。
  - 文法: 11機能のセクション。
- 各セクションは折りたたみ可（任意・YAGNI判断）。カテゴリ内順は元データ順（安定）。
- カバー率/進捗の計算は既存のまま（分類は表示のみ、item集合は不変。ただし文法へ移した24語はvocab集合から外れる）。

## 8. テスト / 検証
- タクソノミー: 全カテゴリidが一意・umbrella参照が有効。
- 割当網羅: 全漢字/全語彙(移管24除く)/全文法が**ちょうど1カテゴリ**に属す（未割当0・重複0）を`node`テストで保証。
- セクション化純関数 `groupByCategory(items, mapping, taxonomy)` をテスト（順序・見出し・空セクション除外）。
- tsc緑・全テスト緑・新規テストは `app/package.json` に登録。
- 実機: 単語タブが各種類でセクション表示・自レベルのみ・数字漢字の数え方が例に出る。
