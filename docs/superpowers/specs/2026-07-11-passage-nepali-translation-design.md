# 本文ネパール語訳（回答後トグル）設計書

**日付**: 2026-07-11 / **アプリ**: safa まいにちJLPT（gitルート `app/`）
**状態**: 設計承認済み（ユーザー2026-07-11「進めて」）。

## 目的
読解(全大問)＋文章の文法の**本文**をネパール語訳し、回答後にトグルで本文下に表示（l1=ne学習者の内容確認補助）。設問・選択肢は訳さない（日本語で解く力を測るため）。

## 対象・データ
- 対象＝`reading.json`(357文)＋`passageGrammar.json`(120セット・N5は2文)の**本文のみ**。約517本文。
- 生成源テキスト＝本文の**ふりがな除去**版。文章の文法は**空欄を正解で埋めた完成文**を訳す（回答後＝内容理解補助のため）。
- 保存＝`src/data/exam/passageTransNe.json`（同梱・ne専用）: `{ "<PassageSet.id>": ["本文0のネ訳", "本文1のネ訳(N5のみ)"] }`。key＝読解id / pg-id。

## UI
- `PassageSetPlayer` に、**`revealed`（全問回答済）かつ `state.settings.l1==='ne'` かつ 当該setの訳が存在**するとき「**翻訳を見る/隠す**」トグルを表示。押下で各 `passages[i]` の下にネパール語訳を表示。回答前は非表示。
- 訳が無いset/言語では何も出さない（no-op）。

## 生成（実費¥0・in-session）
- CLAUDE.md #9準拠：少数の大きめエージェントで束ね翻訳、各自ファイルWrite、gen内自己検証（全setId網羅・空文字なし）。まず少数パイロットで形式確認→全量。
- 検証スクリプトで「全setId(reading+passage_grammar)に非空の訳がある」ことを確認。

## 非対象
- 他言語（今回ne只・後日同型で追加可）。設問/選択肢の翻訳。

## テスト
- `passageTransNe.json` が全 reading id ＋ 全 pg セットid を網羅し、各値が非空配列（N5は2要素）であること。
- UI: revealed×l1='ne'×訳ありでトグルが出る／それ以外は出ない（純判定関数を抽出してテスト可）。
