# 桜の口調シート（正本・1枚固定）

台詞は1回目でなく**500回目**に評価される。3週間毎日開いた人が「安っぽい」と感じる原因は、ほぼ台詞の反復と揺れ。**このシートを固定してから各フェーズの文言を書く**（後から通すと全部書き直しになる）。

## 基本

| 項目 | 決定 |
|---|---|
| 一人称 | 「わたし」 |
| ユーザーの呼び方 | 原則、呼ばない（日本語は主語省略が自然でやさしい）。必要時のみ「あなた」 |
| 敬語 | 使わない（距離ができる）。ただしタメ口に崩さない |
| 語尾 | 〜だね／〜よ／〜ね／〜かな／体言止め |
| 文の長さ | 全角24字以内・最大2文（ルビが乗るので長いと崩れる） |
| 語彙 | N5話者が読める語。難語は言い換え、全語ルビ |
| 絵文字 | 使わない（🐚 は UI 側の記号であり桜の言葉ではない） |
| 感嘆符 | 1文に最大1つ。多用すると軽くなる |

## 禁止表現（本体）

| 種類 | 禁止例 | 理由 |
|---|---|---|
| 責める | サボった／また休んだ／ダメだよ | 罪悪感で戻す設計は長期を焼く |
| 煽る | 今だけ／逃してしまう／あと少しで失う | 販促の声と桜の声を絶対に混ぜない |
| 誇張 | すごい！天才！さすが！ | 乱発すると全部の褒めが無効化する |
| 能力の評価 | 頭いいね／才能あるね | 過程を褒める（できなかった日に反転する） |
| 比較 | 他の人より／平均より | 相棒がやることではない |
| 数値の押し付け | あと3問で目標達成 | 数字は UI が言う。桜は言わない |
| 属性言及 | 国籍・宗教・政治・容姿・年齢 | 既存のボーダーレス方針 |

## 価値観（迷ったときの判断基準・この2行で9割決まる）

- **桜は結果ではなく「来たこと」を見る。**
- **桜は何も頼まない。ただ覚えている。**

## 柴犬は一言も話さない

犬は感情の増幅器。桜が静かに一言 → 犬が跳ねる＝喜びが2倍になるが台詞は1本のまま。復帰時は犬が先に気づいて駆け寄り、桜は後から静かに一言。言葉を増やさず表現の幅が増え、犬の口調管理コストがゼロになる。

## 台詞の合成＝2段組み（全掛けは破綻：状態7×願い6×季節4×時間帯3×3案=1,512行）

- **core（一文目）**：願いが効くのは「復帰・節目・大試前後」の4状態だけ。他3状態は願い非依存。→ 4状態×6願い×3案 + 3状態×3案 = **81行**
- **flavor（二文目・付いたり付かなかったり）**：季節4×3案 + 時間帯3×3案 = **21行**
- 合計約100行で数百通りの見え方。同じ core でも flavor で印象が変わる。

## 反復回避

ランダム抽選は必ず連続で同じものを引く。**直近に使ったIDを保持して除外**する。

## 多言語（翻訳者へ必ずこのシートを添付）

- 英語は主語省略ができず you が全文に出て説教くさくなる → 意図的に省く工夫を指示。
- ネパール語等は敬語階層の選択が必須。訳者が勝手に決めると桜の距離感が変わる → レベルを指定。
- 「〜だね」の柔らかさは直訳できない → **文字数でなく「温度」で訳す**よう指示。
- 最低限、**「禁止表現」と「価値観の2行」**を翻訳依頼書に添付する。
