# 桜の口調シート（正本・1枚固定）

台詞は1回目でなく**500回目**に評価される。3週間毎日開いた人が「安っぽい」と感じる原因は、ほぼ台詞の反復と揺れ。**このシートを固定してから各フェーズの文言を書く**（後から通すと全部書き直しになる）。

## 基本

| 項目 | 決定 |
|---|---|
| 一人称 | 「わたし」 |
| ユーザーの呼び方 | 原則、呼ばない（日本語は主語省略が自然でやさしい）。必要時のみ「あなた」 |
| 敬語 | 使わない（距離ができる）。ただしタメ口に崩さない |
| 語尾 | 〜だね／〜よ／〜ね／〜かな／体言止め |
| 文の長さ | 全角24字以内・最大2文（ルビが乗るので長いと崩れる） |
| 語彙 | N5話者が読める語。難語は言い換え、全語ルビ |
| 絵文字 | 使わない（🐚 は UI 側の記号であり桜の言葉ではない） |
| 感嘆符 | 1文に最大1つ。多用すると軽くなる |

## 禁止表現（本体）

| 種類 | 禁止例 | 理由 |
|---|---|---|
| 責める | サボった／また休んだ／ダメだよ | 罪悪感で戻す設計は長期を焼く |
| 煽る | 今だけ／逃してしまう／あと少しで失う | 販促の声と桜の声を絶対に混ぜない |
| 誇張 | すごい！天才！さすが！ | 乱発すると全部の褒めが無効化する |
| 能力の評価 | 頭いいね／才能あるね | 過程を褒める（できなかった日に反転する） |
| 比較 | 他の人より／平均より | 相棒がやることではない |
| 数値の押し付け | あと3問で目標達成 | 数字は UI が言う。桜は言わない |
| 属性言及 | 国籍・宗教・政治・容姿・年齢 | 既存のボーダーレス方針 |

## 価値観（迷ったときの判断基準・この2行で9割決まる）

- **桜は結果ではなく「来たこと」を見る。**
- **桜は何も頼まない。ただ覚えている。**

## 柴犬は一言も話さない

犬は感情の増幅器。桜が静かに一言 → 犬が跳ねる＝喜びが2倍になるが台詞は1本のまま。復帰時は犬が先に気づいて駆け寄り、桜は後から静かに一言。言葉を増やさず表現の幅が増え、犬の口調管理コストがゼロになる。

## 台詞の合成＝2段組み（全掛けは破綻：状態7×願い6×季節4×時間帯3×3案=1,512行）

- **core（一文目）**：願いが効くのは「復帰・節目・大試前後」の4状態だけ。他3状態は願い非依存。
- **flavor（二文目・付いたり付かなかったり）**：core が1文のときだけ付く（合成後も最大2文）。主に daily を希釈。
- 同じ core でも flavor で印象が変わる。

## 配分は「重要度」でなく「その棚で実際に引く回数」に比例させる（均等割りは誤り）

均等8枚は棚で事情が違い破綻する：**A(1-3日)は3回しか引かない**(8枚中5枚が死蔵)、**C(31日〜)は無限**(8枚を永久に周回＝一番バレる)。引く回数に比例して配り直す。

### daily(出迎え)は streak棚で引く回数に比例。C は片道なので割り続ける

| 棚 | 引く回数 | 行数 | メモ |
|---|---|---|---|
| A 1-3日 | 3回だけ | **4** | 4本で十分・4本浮く |
| B 4-30日 | 27回 | **14** | 27日で2周弱＝気づかれにくい |
| C1 31-90日 | 無限区間の入口 | **18** | 唯一の無限区間。厚みが要る |
| C2 91-365日 | — | 20（**後払い**） | 到達は最短3か月後に書けばよい |
| C3 366日〜 | — | 12（**後払い**） | 「一年、通ったね」の棚 |

**在庫の後払い**＝この棚方式の一番おいしい性質。31日到達は最短でリリース1か月後・その頃には実使用が分かり良い台詞が書ける。未執筆の C2/C3 は下位棚（C1）へ自動フォールバック（`pickCore`）。

### flavor は「同時に使える数」で数える（春は春の在庫しか使えない）

| flavor | 行数 | メモ |
|---|---|---|
| 季節 | 4季×**8**=32 | 春90日×出現40%÷8≒4〜5周。夏の在庫は春には存在しない |
| 時間帯 | 3帯×**6**=18 | 同時使用14前後で1季2〜3周に収める |

掛け算（呼びかけ×本文）は見た目を増やすが、**新鮮味は本文の数でしか増えない**（人は特徴的な本文だけ覚え、呼びかけは背景で記憶に残らない）。水増しに頼らず本文の本数を確保する。

### 変化は出迎えでなく「出来事」が運ぶ（役割分担）

挨拶は繰り返すのが自然（毎朝ちがう名言を言う家族は不気味）。危ないのは繰り返しでなく「機械が回してる」と分かること。**C棚＝変わらない安心**を担当し、新鮮味は別レイヤーが持つ：季節(年4)・100/365の節目・語の卒業(週1)・連載(週1)・大試/合否(年1-2)。200日目の人は出迎えでなくこちらで世界を感じる。

### その他の core（願い依存は発火が年数回＝薄く）

| 機会 | 行数 | メモ |
|---|---|---|
| session_end | 12 | 減衰で none へ |
| comeback ×6願い | 18(+neutral3) | 3段階(空白の長さ)×6・復帰は効きどころ |
| word_graduate | 8 | 手習いの間で苦手語を卒業(週1) |
| exam ×6願い | 18(+neutral3) | 前夜/当日/翌日×6 |
| result ×6願い | 12(+neutral2) | 合/否×6 |
| milestone ×6願い | 6(+neutral1) | リング満ち等 |
| streak_mark | 4 | 連続の節目・再登場しない |
| fragment(連載) | 20 | 順不同・答えを出さない・再登場しない |

**執筆順＝発火頻度順**（いつ止めても穴が空かない）。**リリースに要るのは A4+B14+flavor50 ＝ 約68本**。C(C1以降)は最初のユーザーが31日目に届く直前まで書かなくてよい。①daily(A/B)+flavor→②session_end→③comeback→④exam/result→⑤fragment。正本の実装＝`src/story/voice.ts`（`voice.test.ts` が24字/2文/絵文字なし/配分数/後払いフォールバックを機械強制）。

## 反復回避

ランダム抽選は必ず連続で同じものを引く。**直近に使ったIDを保持して除外**する。

## 多言語（翻訳者へ必ずこのシートを添付）

- 英語は主語省略ができず you が全文に出て説教くさくなる → 意図的に省く工夫を指示。
- ネパール語等は敬語階層の選択が必須。訳者が勝手に決めると桜の距離感が変わる → レベルを指定。
- 「〜だね」の柔らかさは直訳できない → **文字数でなく「温度」で訳す**よう指示。
- 最低限、**「禁止表現」と「価値観の2行」**を翻訳依頼書に添付する。
