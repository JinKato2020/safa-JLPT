## 0. 目的と優先度

**学習効率（少ない時間で合格率が最も上がる）と 合格率分析（どの区分・大問で落ちるか予測）に全ふり**する、面別マスタリー方式の学習/出題エンジンを新設する。

- 既存の準備度/SRSエンジン（`app/src/engine/engine.ts` の 1語1p, `computeReadiness` 等）は**「過去の残骸」扱い＝制約にしない**。面別に予測する新エンジンへ**作り直してよい**。「既存を壊さない」を設計理由に使わない。
- 多言語化は**日本語で作り込んでから**展開（修正のたび10言語直しを避ける）。
- ①カード整合性は完了済み（本設計の前提。C6無例文95→0、漢字カード全面刷新、ルビ/下線恒久修正済）。

## 1. アイテムと「面（facet）」

### 1.1 アイテム種別（在庫）
| 種別 | 件数 | 正データ |
|---|--:|---|
| 語彙 | 3,525 | `app/src/data/vocab.json` |
| 漢字 | 612 | `app/src/data/kanjiCards.json` |
| 文法 | 393 | `app/src/data/grammar.json` |
| 読解 | 技能（**有限在庫なし**） | 別トラック（後述） |
| 聴解 | 技能（**有限在庫なし**） | 既存 listening パイプライン |

### 1.2 面＝**単語タブの問題構造**（学習タブとは別系統）
**重要**: 2タブは「同じ面を深さ違いで問う」のではなく、**別の問題システム**（§2）。以下は**単語タブ**の面:
- **語彙 ＝ 音 ↔ 意（2面）**: 音→意(受容4択) ／ 意→語(産出・かなタイルで綴る)
- **漢字 ＝ 3問**:
  1. **聞き取り(受容)** ＝ 🔊読み → 漢字を選ぶ（**単字**。複合語にしない＝語彙化を避ける）
  2. **書き取り(産出)** ＝ 漢字を書く
  3. **意味(受容)** ＝ 漢字 → 意味（**明快字のみ**）
  - 「漢字→読みを答える」は**学習タブの漢字読み大問と重複するため作らない**。「テキスト表記→漢字」も聞き取り(音→漢字)と重複するため作らない。
  - **bound字**（校＝コウ等）も聞き取りを出す：**辞書的に音読み「コウ」を読み上げ → 校 を選ばせる**（案b・網羅優先）。
- **文法 ＝ 並べ替え(一意) ＋ 意味(問える点のみ)**:
  - 並べ替え(産出) ＝ タイルを順に並べる（学習タブの★スロットとは別物）。日本語は語順自由で複数正解になり得るため**一意に決まる問題だけ生成**。**全文でなく文の一部(句)をタイル化**すると一意化しやすく作りやすい（割れる箇所は避ける）。
  - 意味(受容) ＝ **意味が言える点のみ**（どうやって／がほしい／たり〜たり 等）。構造的で意味を言いにくい点は並べ替えのみ。

**学習タブの面＝本番の大問**（漢字読み/表記/文脈規定/言い換え/用法/語形成・文法形式/並べ替え(★)/文章・読解・聴解）。単語タブとは**別の分解**（例: 単語タブ語彙＝音/意の2 vs 学習タブ語彙＝5大問）。

### 1.3 「漢字は漢字が担当」＝語の読み/表記は漢字習得から合成
- 本番JLPTは**単独漢字の意味を問う大問が存在しない**。漢字力は必ず**語**を通して測る（漢字読み＝語→読み、表記＝かな→漢字）。
- よって**語彙アイテムのコアは 音↔意 の2面だけ**。語の「漢字読み・表記」は独立面として持たず、**構成漢字（漢字アイテム）の習得度から合成**して予測する。
- **スコープ判定**: 語の構成漢字が「そのレベルで学習対象（漢字カード集合＝612字 かつ ≤当該レベル）」に**すべて収まる**語だけが、漢字読み/表記の対象。
  - 実測: 万年筆（n5-v-634）＝万(N5)・年(N5)・**筆(スコープ外)** → N5では音＋意のみ。
  - レベル別「一部の漢字がスコープ外＝音+意でよい語」: N5=118 / N4=169 / N3=925（実測）。
- 漢字の**意味面**は「意味が明快な字」に限定。束縛/抽象字（校・不・以・的 等）は意味選択にせず、**語の中で問う**。判定リストを事前生成（作業タスク §7）。

### 1.4 マスタリー状態
- 状態の単位 ＝ **(アイテム × 面)＝1本**。両タブの正答が同じ面を育てる。
- 各面 **3段**: `未習` → `受容済`（正解し**SRS間隔が一定以上に伸びた**）→ `産出済`（単語タブ産出で安定＝満段）。
- 数値: 各面に **習得度 m ∈ [0,1]**（受容確率）。**SRSで時間減衰**（放置で低下）。段はしきい値で表示。
- **SRSは (アイテム×面) で一本**。学習タブ・単語タブの両方の正答が同じ状態を更新（学習タブの1問も根っこの語×面に還元して更新）。別々にdue管理しない。

## 2. 2タブ ＝ 別の問題システム（目的も問題も指標も別）

| | 学習タブ | 単語タブ |
|---|---|---|
| 位置づけ | **本番試験に寄せた既成問題**（試験特化・出題形式は**固定・柔軟でない**） | 学習タブの**弱点を補う柔軟な問題**（大量学習用） |
| 問題 | すでに試験に最大限近づけて作成済み | 学習タブと**被らない**別問題（音声→意味、完全並べ替え 等） |
| 出題 | **アプリが自動で並べて出す**（ミックス／大問の2モード・どちらもSRS） | カードを選び「**学習→問題**」・面×形式をSRSでバランス |
| 指標 | **正答率**（→大問→区分→合格率） | **カバー率**（学習の広がり） |
| 形式 | 受容中心（本番大問） | 受容・産出の両方 |
| バランス学習ボタン | **削除** | — |

- **カバー率は両タブの問題結果から合算**して算出（受容済で1台=A案）。ただし**学習タブ画面にはカバー率を表示しない**。
- 面の粒度が違う（§1.2）。「同じ面を深さ違いで問う」ではない。

### 2.1 単語タブの情報設計（IA）と挙動
各「練習」は **学習（教える）→ 問題** の順。**ゆるやかに受容→産出**（新規は受容から、習得で産出比率↑。最初から半々にしない）。

```
漢字カード
  漢字リスト
  漢字練習 … 聞き取り(🔊読み→漢字を選ぶ・受容) / 意味(漢字→意味・受容/明快字のみ) を選ぶ → 学習 → 問題
  書き取り練習 … 漢字を書く（産出）
  ※bound字(校=コウ等)も聞き取りを出す＝音読みを読み上げて漢字を選ばせる

語彙カード
  語彙リスト
  語彙練習 … 聞き取り(🔊→意味・受容) / 意味→語(かなタイルで綴る・産出) を選ぶ → 学習 → 問題

文法カード
  文法リスト
  文法練習 … 並べ替え(文の一部をタイルで順に並べる・産出/一意のみ) / 意味を問う(受容・意味が言える点のみ) を選ぶ → 学習 → 問題
  ※文章(passage)面は単語タブに置かない（学習タブのみ）
```

### 2.2 受容⇄産出のラダー
- 受容 ＝ 見て/聞いて選ぶ（4択）。産出 ＝ 自分で作る（かなタイル綴り・完全並べ替え・書き取り、ダミー不要）。
- 「産出できる＝受容もできる」。単語タブで産出まで到達＝その面が満段。

### 2.3 単語タブ UI 確定（ユーザー承認 2026-07-10・[[wordtab-ui-coverage-badges]]）
- **専門用語をUIに出さない**: 「面別/受容/産出」は開発用語。ユーザーが見るのは**カバー率バー＋成長バッジのみ**。弱点分析は裏でSRSが行い出題へ自動反映。
- **最上部に「オススメ学習セット」**（SRSが弱点を自動選択・約15問）。その下に3カード、各カードに**カバー率バー＋成長バッジ＋ボタン群を内包**（別メニュー画面に飛ばさない）。
  - 漢字: リスト/練習/聞き取り/書き取り　語彙: リスト/問題　文法: リスト/問題
- アイコンは**白黒シンプル**（単色ライン）。
- **漢字 書き取り(改)**: 漢字を見せず意味・読みから**記憶で書く・枠1つ・なぞり無し**→書いた後に正解表示。
- **成長バッジ＝漢字10段画像**（`画像/バッジ・勲章/漢字/分割/漢字_01..10.png` あ→知→超）。**カバー率10%刻みで1→10段**、**語彙・文法も同画像を共通利用**。既存 `home.coverTier0..9`(カバー率10段)の視覚アセット。大リング合格率称号(passTitle系)とは別軸。
- モック（承認済）: `scratchpad/wordtab-mockup.html`（Artifact公開）。

### 3.5 単語タブ問題の distractor（選択肢）生成ルール
実データで検証済（scratchpadサンプルで確認）。**全て決定論・¥0**。LLMは原則不要（質が要る所だけ後で一括見積→承認）。
- **産出系はダミー不要**: 意→語(かなタイル綴り)・完全並べ替え(タイル)・書き取り。← 最も確実。
- **受容4択のダミーは「紛らわしさ」ルールで選ぶ**（同レベルから機械的に拾うと易しすぎる＝実測で確認）:
  - 語彙 音→意: **同じ品詞**（意味の "to ~"=動詞 等で推定）＋語長近似。
  - 漢字 聞き取り(音→漢字): **同じ音読みの別字**（コウ→高・工・口）が最も紛らわしい。
  - 漢字 意味: 数字/機能語を除いた**同レベルの近い意味**。
  - 文法 意味: 同レベルの別文法点の意味。

## 4. 出題選択ロジック

### 4.1 役割分担
- **SRS忘却モデルが「出題」を駆動**（＝学習効率）。
- **面別マスタリー → リングが「合格率」を表示**（＝分析）。
- 出題はSRS、分析はリング、と役割を分ける。

### 4.2 学習タブ（自動出題）
- 2モード（ミックス出題／大問出題）。範囲は違うが、選択はどちらも**SRS忘却モデル**（忘れそうな順＋未到達を混ぜる）。
- 出題形式は**本番大問の形式**（受容中心）。

### 4.3 単語タブ（カード別）
- 選んだ面について「学習→問題」。**面×形式（受容/産出）をSRSでバランス配分**、**ゆるやかに受容→産出**。

## 5. 可視化（リングとバー）

```
大リング  合格率 = f(正答率, カバー率)
 └ 中リング（4表示）  語彙・漢字 / 文法 / 読解 / 聴解 … 区分の正答率
     └ 小リング  大問の正答率
         ├ 文字語彙: 漢字読み・表記・文脈規定・言い換え・用法・語形成
         ├ 文法:    形式判断・並べ替え・文章
         ├ 読解:    内容理解(短/中/長)・情報検索 …
         └ 聴解:    課題理解・ポイント理解・概要理解・発話表現・即時応答
```
- 小リング（大問）＝**学習タブの大問正答率**（本番の大問）。大問→中→大とフラクタルに積み上がる。
- 正答率(質)←**学習タブ** ／ カバー率(量)←**両タブ合算**。合格率＝両方から。
- **中リングは4表示**（語彙漢字/文法/読解/聴解）＝診断に良い（文法だけ弱いが一目で分かる）。**表示は4、合格判定は公式区分**（§6）。
- **カバー率バー ＝ 語彙 / 漢字 / 文法**（読解・聴解は有限在庫が無いので無し）。
  - **到達しきい値＝受容済（A案）**: 見て分かる＝1台カウント。産出済は「正答率/質」を押し上げるがカバー率は受容で足りる（本番＝多肢選択＝受容力で解ける）。
  - **両タブから合算**: アイテムの面マスタリーは1本。学習・単語どちらの正答でも受容済に到達可＝自動合算。

## 6. 合格率の数式

### 6.1 積み上げ（下→上）
1. **1問の予測正答率**: `p = 推測下限 + (1 − 推測下限) × 習得度`
   - 習得度＝SRS減衰後の受容マスタリー（0〜1）。
   - 推測下限＝4択なら 0.25（大問の選択肢数に応じる）。
   - 例: 習得度0.8の漢字読み → p=0.85 ／ 未習 → p=0.25。
2. **大問（小リング）期待**: その大問のプール（対象アイテム）の **p の平均**。
   - カバー率が自動で効く（未習=0.25が平均を下げる）。
   - **読解・聴解は在庫が無いので例外**: 学習タブで**実際に解いた正答率**を期待値に使う（試行が少ないほどブレを大きく取る）。
3. **区分（中リング）**: 大問を問題数で重み付け合計→ 0〜60（N4/5一部は0〜120）スケールへ。
4. **合格条件**: **全区分が基準点以上 かつ 総合が合格ライン以上**。
5. **大リング＝合格率（確率）**: 期待点の○×ではなく、**同じ実力で本番を何千回受けたら何回受かるか**（モンテカルロ）。各大問の点を予測正答率のサイコロで毎回振り、④を満たした割合。
   - 線ギリギリなら合格率≈50%、余裕で超えれば90%超。勉強でなめらかに上がる。

### 6.2 得点区分（基準点）＝公式ルール（レベルで異なる）
| レベル | 得点区分（基準点がかかる単位） | 合格 |
|---|---|---|
| N1/N2/N3 | ①言語知識＝**語彙漢字＋文法**(0〜60・基準点19) ②読解(0〜60・基準点19) ③聴解(0〜60・基準点19) | 全区分≥基準点 かつ 総合≥（N3=95・N2=90・N1=100）/180 |
| N4/N5 | ①**言語知識(語彙漢字＋文法)＋読解**(0〜120・基準点38) ②聴解(0〜60・基準点19) | 総合≥（N4=90・N5=80）/180 |

- **文法だけの基準点は存在しない**（語彙漢字と同じ言語知識区分に合算）。
- したがって **中リングは4表示、合格率計算では 語彙漢字＋文法を1区分にまとめる**（N4/5はさらに読解も同区分）。
- 文法に独立基準点を作ると本番より厳しく判定＝合格率が過小になる（不正確）。**表示4・判定は公式区分**を厳守。

- 得点区分・基準点: https://www.jlpt.jp/guideline/results.html

## 7. コンポーネント分割（実装単位・独立してテスト可能に）

1. **MasteryStore**: `(itemId, facet) → { m, 段, reps, ease, intervalDays, dueAt, updatedAt }`。永続化。
2. **SrsScheduler**: 忘却減衰（effectiveM）、due計算、**出題選択**（学習タブ2モード／単語タブ面×形式バランス）。
3. **ProblemProviders**: 各バンク→問題を供給。
   - `LearnTabProblems`: 学習タブ＝既成の本番大問（バンクをそのまま）。
   - `WordTabProblems`: 単語タブ＝§1.2の面から問題を構築（+ `DistractorGen` §3.5）。
     - 漢字: 聞き取り(音→漢字・bound字は音読み読み上げ)／書き取り／意味(明快字)。
     - 語彙: 音→意／意→語(かなタイル)。
     - 文法: 並べ替え(**文の一部を一意タイル化**)／意味(問える点)。
   - `GrammarTagger`: 文法問題(2413)↔文法点(393)の**自動タグ付け＋検証**（表層パターン照合）。
   - `UniqueOrderExtractor`: order/例文から**一意に並ぶ句を抽出**（単語タブ並べ替え用）。
   - `KanjiScope`: 語→構成漢字→スコープ内判定。 / `KanjiMeaningClear`: 明快字リスト。 / `KanjiBound`: bound字リスト(音読み読み上げ対象)。
4. **PassRateEngine**: マスタリー→大問期待→区分→**モンテカルロ合格率**。区分グルーピング（レベル別・公式）。
5. **RingViewModels**: 大/中(4)/小リング＋カバー率バーの算出（表示は4、判定は公式区分）。
6. **UI**:
   - 学習タブ: 自動出題キュー（バランス学習ボタン削除）。
   - 単語タブ: カード別「学習→問題」。漢字/語彙/文法の練習メニュー（§2.1）。
7. **合格リング称号**: 大リング合格率tier → `badgeTierIndex`(0〜9) → 既存i18n `home.passTitle*`/`natPassTitle*`（称号システムは流用）。

各コンポーネントは「何をするか・どう使うか・何に依存するか」が単独で言える境界を保つ。`engine.ts` の既存API（computeReadiness 等）は本エンジンへ置換する。

## 10. リスク・要検証
- **習得度→p の較正**: 初期はヒューリスティック。実データで調整（ビルド緑≠実行時安全＝node実行＋nullガードで検証）。
- **モンテカルロの計算タイミング**: 毎レンダーでなく**マスタリー更新時に再計算＋キャッシュ**（数千ドローは安価）。
- **文法タグ付けの被覆率**: 短い/頻出形（だけ 等）は過剰マッチ。被覆率を先に実測し、低ければ手当て方針を決める。
- **読解問題の在庫**: 無い場合、読解リングは初期「未測定」。
