# 3タブ没入UI一新 設計仕様（単語・試験・辞書）

- 日付: 2026-07-12
- 対象アプリ: まいにちJLPT（`app/` = Expo SDK54 / RN 0.81 / TypeScript）
- ステータス: 設計確定（実装計画待ち）

## 1. 目的（なぜ）
単語・試験・辞書の3タブを、ユーザー提供の**全画面イラストを背景**にした**没入UI**へ一新する。フラットな不透明カードをやめ、世界観（桜の巫女・和の学び舎）に没入できる見た目にしつつ、既存の学習機能は一切失わない。

## 2. スコープ
### 対象
- 単語タブ（WordsTab）／試験タブ（アプリ内ラベル「学習」= StudyScreen 相当）／辞書タブ（BrowseScreen）の**ホーム表現**の刷新。
- 3つの全画面背景の同梱と最適表示。
- タブごとに最適な入口方式（没入ホットスポット or 和紙調タイル）の実装。
- 既存機能への遷移配線（詳細画面へ移設して保全）。

### 対象外
- ホーム／設定タブ（現行のまま）。
- 昼夜切替（今回の高解像度画像は各タブ1枚のみ提供のため**当面なし**。夜画像が用意され次第、別タスクで復活可）。
- 文章の文法の内容監査、アカウント機能（別プロジェクト）。
- 出題エンジン・SRS・辞書データそのもの（不変）。

## 3. 確定した設計判断（ユーザー承認済み 2026-07-12）
1. **背景の描き込みとUIの重複**は「**タブごとに最適な方を混在**」で解決する。
   - 単語＝背景に**掛軸/札が描かれている**ので、それ自体をボタン化（没入ホットスポット・タイルなし・重複ゼロ）。
   - 試験・辞書＝背景に機能ラベルが無い（または少ない）ので、**和紙調タイル**を重ねる。
2. **昼夜**＝当面1枚（切替なし）。
3. **模試の履歴（棒グラフ）**＝試験ホームから撤去し、**模試（Mock）フロー側に集約**。

## 4. 背景マッピング（正本と同梱）
- 正本: `画像/アプリ画像/学習タブ.PNG`（単語）・`試験タブ.PNG`（試験）・`図書館.PNG`（辞書）。853×1844（≒スマホ比）。
- 同梱: JPG(q88)へ変換し `app/assets/tabs/word_bg.jpg`・`exam_bg.jpg`・`dict_bg.jpg`（各≈420–500KB）。`require()`で同梱（バッジ方式踏襲）。
- 表示: `resizeMode:'cover'` ＋ 親コンテナ `overflow:'hidden'` で**画面外へはみ出さない**（「画像が画面からはみ出す」問題の恒久解決）。アスペクトが端末とほぼ一致するため切れは最小。

## 5. アーキテクチャ
### ナビゲーション（既存パターン＝ネストスタックを踏襲）
- `WordsStack`: `WordsHome`(ハブ) → `WordKubun`{kubun}(区分練習) → `WordList`(BrowseScreen study)
- `StudyStack`: `StudyHome`(タイル) → `StudyCategory`{cat}(カテゴリ詳細)
- `DictStack`: `DictHome`(タイル) → `DictList`{view}(BrowseScreen dict)
- 各タブは `MainTabs`(material-top-tabs, 下配置) 内の1画面。My単語帳・Quiz・Mock 等は従来どおり RootStack モーダル。

### 共通部品 `src/components/TabScene.tsx`
- `TabBackground({source, scrim?})`: 全画面背景(cover)＋任意暗幕。`overflow:'hidden'`。
- `ImmersiveHome({bg, title, scrim?, children})`: 背景＋中央タイトル＋タイルグリッド(ScrollView)の共通レイアウト。
- `ImmersiveTile({glyph, label, sub?, count?, accent, onPress})`: 和紙調の半透明タイル（金の細枠・大グリフ・任意サブ文言・任意件数バッジ）。
- `Hotspot({area, onPress, label})`: 背景の描き込み要素に重ねる透明タップ領域（% 指定・押下で淡く発光）。
- 色トークン `IMMERSIVE`（card/sheet/gold）。

### アセット定義 `src/data/tabArt.ts`
- `TAB_BG: Record<'word'|'exam'|'dict', ImageSourcePropType>`。

## 6. タブ別設計
### 6.1 単語（没入ホットスポット）
- 全画面 `TAB_BG.word`。scrim なし（掛軸が主役）。
- Hotspot（背景の描画位置に % で重ねる。座標は実機で微調整前提）:
  - 掛軸「語彙」→ `WordKubun{kubun:'vocab'}`
  - 掛軸「文法」→ `WordKubun{kubun:'grammar'}`
  - 掛軸「漢字」→ `WordKubun{kubun:'kanji'}`
  - 「今日の目標」札 → `WordDrill{kind:'mixed'}`（今日のオススメ）
- `WordKubun` = `CardsScreen` に `kubun` パラメータを追加し、その1区分のみ表示（カバー率＋区分の各ドリル＝一覧/産出/意味/並べ替え/聞き取り/書き取り）。上部に「←戻る」。区分指定時は「今日のオススメ」カードは出さない（札が担うため）。

### 6.2 試験（和紙調タイル → カテゴリ詳細）
- 全画面 `TAB_BG.exam`。scrim ≈0.16。`ImmersiveHome` タイトル「試験（study.title）」。
- タイル（`ImmersiveTile`）:
  - 「オススメ」→ `Quiz{category:'all'}`
  - 「文字語彙／文法／読解／聴解」各カテゴリ（正答率% を sub 表示）→ `StudyCategory{cat}`
  - 「模試」→ `Mock{full:true}`（`fullMockLocked` がロック中は非活性＋次回時刻を sub 表示）
- `StudyCategory{cat}` = 旧 StudyScreen の1カテゴリ分を移設：全体正答率リング＋ミックス出題(10)＋大問毎リング(タップで個別10問/文章の文法は専用画面)＋凡例。上部に「←戻る」。
- **模試履歴**は本ホームから撤去し、模試フロー（Mock 結果/専用画面）に集約（別途 Mock 側で表示）。

### 6.3 辞書（和紙調タイル）
- 全画面 `TAB_BG.dict`。scrim ≈0.12–0.16。`ImmersiveHome` タイトル「辞書（dict.tab）」。
- タイル:
  - 「語彙」→ `DictList{view:'vocab'}`、「漢字」→ `{view:'kanji'}`、「文法」→ `{view:'grammar'}`
  - 「My単語帳」（件数バッジ）→ `MyWords`
- `DictList` = `BrowseScreen`（params 付き＝辞書モード）。既存の検索/区分セグメント/レベル絞り込み/一覧はそのまま。「×」で `DictHome` に戻る。

## 7. 機能保全と移動
- 保持: 各ドリル（一覧/産出/意味/並べ替え/聞き取り/書き取り）、カテゴリのミックス/大問、辞書検索、my単語帳、カバー率バッジ算出、模試本体。
- 移動: 模試履歴（棒グラフ）→ 模試フロー側。
- 撤去: 昼夜トグル（画像1枚のため）。

## 8. 可読性・パフォーマンス
- タイル/シートは半透明（和紙調）＋金の細枠＋影で背景と分離しつつ透け感を残す。暗幕は最小限（文字可読性を確保できる範囲）。
- 背景は同梱JPG（各≈0.5MB）。`require()` 即時表示。追加ネットワークなし。
- 既存テーマ（水彩/ダーク等）とは独立に、タブ背景は常にイラスト（没入優先）。

## 9. テスト
- `npm run tsc` 緑。
- `npm test`：既存192を維持。追加候補＝カバー率%整形・カテゴリ→詳細のパラメータ写像などの純関数（新規 `*.test.ts` は `app/package.json` の test スクリプトに追加）。
- 手動（トンネル/実機）: 3タブの背景がはみ出さず表示／単語の掛軸・札タップで各遷移／試験タイル→カテゴリ詳細→出題／辞書タイル→各リスト→戻る／My単語帳件数。

## 10. 未確定・要実機調整
- 単語のホットスポット座標（掛軸3・札1）は目測初期値。実機で微調整する。
- 模試履歴の「模試フロー側」での具体的な見せ方（結果画面 or 専用）は実装時に最小構成で確定。

## 11. グローバル制約（計画へ引き継ぐ厳守値）
- git ルート = `app/`。Build番号 = `1000 + git rev-list --count HEAD`。今回は**ビルドせず**（保留中の大型ビルドにまとめる）。
- テストは `node --import tsx --test`。新規 `*.test.ts` は `app/package.json` の `test` に追記必須。
- 個人名を使わない（ボーダーレス方針）。専門用語をUIに出さない（単語タブ既定）。
- 既存ナビ/型の破壊禁止（追加のみ）。アセットは `app/assets/tabs/`。
