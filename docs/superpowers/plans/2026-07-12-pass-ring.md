**Goal:** ホームタブ中央に、react-native-skia で描く多重「合格リング」（外=5科目カバー率／中=総合正答／中央=合格の称号）を、適度なアニメ付きで実装する。

**Tech Stack:** @shopify/react-native-skia, react-native-reanimated（アニメ）, expo-dev-client（Expo Go不可のため実機プレビュー用）。

```ts
import type { AppState } from '../store/state';
import { coverageBars, ringsFor } from '../store/selectors';

export type PassRingCategory = { key: string; label: string; color: string; coveragePct: number };
export type PassRingData = {
  passPct: number; level: string; overallAccuracyPct: number; tier: string; categories: PassRingCategory[];
};

const clamp = (n: number) => Math.max(0, Math.min(100, Math.round(n || 0)));
const COLORS: Record<string, string> = { vocab: '#e75f86', grammar: '#9a86ef', kanji: '#e8934e', dokkai: '#46b6d6', choukai: '#57c78c' };

export function passRingData(state: AppState, now: number): PassRingData {
  const cov = (() => { try { return coverageBars(state, now); } catch { return []; } })();
  const covOf = (k: string) => { const b = cov.find((x: any) => x.key === k); return b && b.total > 0 ? (100 * b.learned) / b.total : 0; };
  const rings = (() => { try { return ringsFor(state, now); } catch { return {} as any; } })();
  const categories: PassRingCategory[] = [
    { key: 'vocab', label: '語彙', color: COLORS.vocab, coveragePct: clamp(covOf('vocab')) },
    { key: 'grammar', label: '文法', color: COLORS.grammar, coveragePct: clamp(covOf('grammar')) },
    { key: 'kanji', label: '漢字', color: COLORS.kanji, coveragePct: clamp(covOf('kanji')) },
    { key: 'dokkai', label: '読解', color: COLORS.dokkai, coveragePct: clamp(rings?.dokkai ?? 0) },
    { key: 'choukai', label: '聴解', color: COLORS.choukai, coveragePct: clamp(rings?.choukai ?? 0) },
  ];
  const accVals = ['moji_goi', 'bunpou', 'dokkai', 'choukai'].map((k) => rings?.[k]).filter((v) => typeof v === 'number') as number[];
  const overallAccuracyPct = clamp(accVals.length ? accVals.reduce((a, b) => a + b, 0) / accVals.length : 0);
  // 暫定合格可能性: カバー率平均×0.5 + 総合正答×0.5（正データ源が出来たら差し替え）。
  const covAvg = categories.reduce((a, c) => a + c.coveragePct, 0) / categories.length;
  const passPct = clamp(covAvg * 0.5 + overallAccuracyPct * 0.5);
  const tier = passPct >= 50 ? '合格' : '挑戦';
  return { passPct, level: state.settings.level, overallAccuracyPct, tier, categories };
}
```

```ts
export const C = 200, R_OUT = 172, R_MID = 128, R_IN = 90;
export function polar(r: number, deg: number): [number, number] { const a = (deg * Math.PI) / 180; return [C + r * Math.sin(a), C - r * Math.cos(a)]; }
export function arcPath(r: number, a0: number, a1: number): string {
  const [x0, y0] = polar(r, a0); const [x1, y1] = polar(r, a1);
  const large = (((a1 - a0) % 360) + 360) % 360 > 180 ? 1 : 0;
  return `M${x0.toFixed(2)} ${y0.toFixed(2)} A${r} ${r} 0 ${large} 1 ${x1.toFixed(2)} ${y1.toFixed(2)}`;
}
```

### Task 4: PassRing コンポーネント（Skia）

**Files:** Create `app/src/home/PassRing.tsx`

**Interfaces:** `export function PassRing({ data, size }: { data: PassRingData; size: number })`

- [ ] **Step 1: 実装**（Skia。外=5セグメント発光弧／中=総合正答の光弧／中央=呼吸する発光ディスク＋称号。弧は `Path` の `start/end` トリムで 0→値。金装飾は回転。）
```tsx
import React from 'react';
import { Canvas, Path, Skia, Group, Circle, RadialGradient, LinearGradient, Blur, vec, Text as SkText, useFont, Paint } from '@shopify/react-native-skia';
import { useSharedValue, withTiming, withRepeat, withSequence, Easing, useDerivedValue } from 'react-native-reanimated';
import { View } from 'react-native';
import { arcPath, C, R_OUT, R_MID, R_IN } from './ringGeometry';
import type { PassRingData } from './passRingData';

const SEG = 72, GAP = 9;
export function PassRing({ data, size }: { data: PassRingData; size: number }) {
  const progress = useSharedValue(0);          // 弧の伸び 0→1
  const breathe = useSharedValue(0.85);        // 中央呼吸
  React.useEffect(() => {
    progress.value = withTiming(1, { duration: 1200, easing: Easing.out(Easing.cubic) });
    breathe.value = withRepeat(withSequence(withTiming(1, { duration: 1700 }), withTiming(0.85, { duration: 1700 })), -1, true);
  }, []); // eslint-disable-line
  const haloOpacity = useDerivedValue(() => breathe.value);
  const scale = size / 400;
  return (
    <View style={{ width: size, height: size }}>
      <Canvas style={{ flex: 1 }}>
        <Group transform={[{ scale }]}>
          {/* 中央: 呼吸する発光＋ディスク */}
          <Circle cx={C} cy={C} r={R_IN + 14} opacity={haloOpacity}>
            <RadialGradient c={vec(C, C - 20)} r={R_IN + 30} colors={['#fff0f6', '#f5b8d2', '#7b4f9c']} />
            <Blur blur={10} />
          </Circle>
          <Circle cx={C} cy={C} r={R_IN}>
            <RadialGradient c={vec(C, C - 18)} r={R_IN} colors={['#fff0f6', '#f5b8d2', '#7b4f9c']} />
          </Circle>
          {/* 外リング: 5科目カバー率 */}
          {data.categories.map((cat, i) => {
            const a0 = i * SEG + GAP / 2, a1 = i * SEG + SEG - GAP / 2;
            const track = Skia.Path.MakeFromSVGString(arcPath(R_OUT, a0, a1))!;
            const fill = Skia.Path.MakeFromSVGString(arcPath(R_OUT, a0, a1))!; // end トリムで cov%
            return (
              <React.Fragment key={cat.key}>
                <Path path={track} style="stroke" strokeWidth={14} strokeCap="round" color="rgba(255,255,255,0.10)" />
                <Path path={fill} style="stroke" strokeWidth={14} strokeCap="round" color={cat.color} start={0} end={progress} opacity={0.95}>
                  <Blur blur={3} />
                </Path>
                {/* 実データ端はcov%。end に cov/100 を掛けたければ progress*cov/100 を別 useDerivedValue で。 */}
              </React.Fragment>
            );
          })}
          {/* 中リング: 総合正答 */}
          {(() => { const p = Skia.Path.MakeFromSVGString(arcPath(R_MID, 4, 356))!;
            return <>
              <Path path={p} style="stroke" strokeWidth={11} strokeCap="round" color="rgba(255,255,255,0.10)" />
              <Path path={Skia.Path.MakeFromSVGString(arcPath(R_MID, 4, 4 + 352 * data.overallAccuracyPct / 100))!} style="stroke" strokeWidth={11} strokeCap="round" start={0} end={progress}>
                <LinearGradient start={vec(60, 60)} end={vec(340, 340)} colors={['#8fe6ff', '#c9a0ff']} />
                <Blur blur={3} />
              </Path>
            </>; })()}
        </Group>
      </Canvas>
      {/* 見出し・称号テキストは RN Text をキャンバス上に重ねる(可読性・多言語・フォント一貫のため)。 */}
      {/* 例: 絶対配置で 知の精進 / 合格可能性% / 試験の実力 / 総合% / 合格 を size 基準に配置。 */}
    </View>
  );
}
```
  - 注: 外リングfillの端＝カバー率%。`end={progress}` は0→1の伸び。**カバー率反映は `end` に `progress*cov/100` を渡す**（各セグメントごとに `useDerivedValue(()=>progress.value*cat.coveragePct/100)`）。実装時にセグメント配列をコンポーネント化して hook 規則を守る（`<Segment/>` を切る）。
  - 見出し/称号は Skia Text ではなく **RN Text をオーバーレイ**（フォント・多言語・可読性の影を既存と揃える）。size 基準の割合で絶対配置。
