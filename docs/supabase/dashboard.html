⚠️ ここに入れる service_role キーは全データを読める“合鍵”です。自分の端末だけで使い、他人・スクショ・共有は厳禁。キーはこの端末のブラウザにだけ保存されます（ファイルには残りません）。

全体サマリー 総ユーザー・今日/週間アクティブはテスト由来（未ログイン＋学習0）を除外した実ユーザー数。登録アカウント/同期/模試/エラーは元の実数

登録者の推移（時系列） アカウント登録数（auth.users の作成日時）の推移。累計＝その日までの総登録者、新規登録/日＝その日に登録した人数。同期済み・匿名端末ではなくアカウント実数（本当の登録数）。横軸＝時間（タイムゾーンUTC・登録ゼロの日は0で補完・直近90日）

🔓 開発モード付与（メール指定） メールアドレスでそのアカウントの開発モード（開発用セクション／大問の問題ID選択など）を解禁／取消します。entitlements.dev_tools を書き込み、対象がログイン中にアプリ起動/再起動で反映。旧「バージョン7回タップで自己解禁」は廃止＝解禁経路はこの管理付与だけ。service_role キーが必要。事前に docs/supabase/admin_grant_dev.sql を一度 SQL Editor で実行しておくこと。

⭐ Pro付与（メール指定） メールアドレスでそのアカウントを恒久Pro（または期限付き／失効）にします。entitlements.pro_until を書き込み、対象がログイン中にアプリ起動/再起動で反映（課金=RevenueCatとは別系統）。service_role キーが必要。事前に docs/supabase/admin_grant_pro.sql を一度 SQL Editor で実行しておくこと。

🏫 学校・先生 管理（団体ライセンス） 日本語学校向け。ここでは学校の作成と先生の登録/削除、各学校の先生数・生徒数（カウントのみ）を扱う。生徒の登録は先生自身が教師専用サイト（teacher.html）から行う（1先生あたり最大20人）。先生は自分が登録した生徒だけを閲覧できる。service_role キーが必要。事前に docs/supabase/school_teacher.sql を SQL Editor で実行しておくこと。先生はアプリ（またはteacher.html）で先にログイン→ここで同じメールを「先生」として登録すればOK。

国別（接続国・定着率・指標） アカウント名寄せ済みの人単位で最新の接続国を集計。テスト由来（未ログイン＋学習0）は除外＝実ユーザーだけ。全体＝実人数（名寄せ済み）／登録＝ログイン済み／匿名＝一度もログインしていない実端末。定着率D1/D7/D30＝インストール後「少なくともN日目まで残った割合」（ローリング）。D7母数が小さいうち（数人）は割合が跳ねる参考値。目安：D1≥40%／D7≥20%／D30≥10%で緑。予想得点＝平均／正:漢語文読聴＝分野別平均正解率（v1.1.35〜のみ）／覆:漢語文＝学習分野別カバー率（平均）／模試回数＝合計・模試得点＝平均／学習回数＝完了練習の合計・学習時間＝合計。平均は測定値がある人だけ。母集団＝右の切替で「7日/30日アクティブ or 全体」を選べる（既定＝7日アクティブ＝インストールしただけの幽霊ユーザーを外した実勢値。全体＝離脱者も含む累計）。定着率D1/D7/D30はコホート指標なので母集団切替の影響を受けない。国はIP由来・旧版は「??」。利用者一覧を消すと国別からも自動で消える ｜ 母集団:

分野別 正解率の分布 5軸（漢字／語彙／文法／読解／聴解）で、正解率（当て推量補正済み）を10%帯に分け、その帯にいる実ユーザーの割合％を表示（各行の合計＝100%）。色が濃い帯ほど人が多い。既定は全体、任意でレベル別も同時表示。アプリ v1.1.35〜が送信＝それ以前しか無い軸は「—」 ｜ 表示:

模試の得点分布 模試の実施回数を得点10%帯に分け、各レベル（＋全体）で分布を表示（色が濃い帯ほど回数が多い・各行の合計＝100%）。回数＝その帯グループの模試回数（合算）。生データ tel_mock は自動削除しないので下の月次推移にも使える

模試の月次推移 月 × レベル（＋全体）で模試回数と平均得点。tel_mock は1回1行（日時つき）なので、月ごとの時間変化がそのまま出せる。積み重ねるほど「上達しているか」が見える

レベル別 在庫（新規の残り） 行＝レベル／列＝大問・単語タブの学習。数字＝いちばん学習が進んでいる人から見た残り＝アプリの問題数−その大問を最も多くやった人の学習数（誰も手を付けていなければ問題数そのもの／誰か1人がやり切れば0）。赤 ≦3＝在庫切れ・橙 ≦20＝要増産。マウスを乗せると問題数と平均も出ます
