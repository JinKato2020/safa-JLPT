# 学習後画面の「ランダム画像」置き場

単語ドリル(単語タブ)を1回終えたときに、上部へ**大きく**出すイラストをここに置きます。
毎回ランダムで1枚選ばれます（世界観の演出＋そのすぐ下に桜貝の獲得数・ねぎらい・10単語チェックリスト）。

## 追加のしかた
1. 画像をこのフォルダに入れる（例: `01.png` `02.png` …）。
   - 形式=PNG または JPG。透過PNGでも可。
   - 推奨=**横長〜正方形**（全幅で大きく表示。縦長すぎると上下が少し切れます）。
   - 目安の比率=3:2〜1:1。長辺 1200px 程度あれば十分きれい。
2. `src/data/afterStudyArt.ts` の配列に1行足す:
   ```ts
   require('../../assets/afterstudy/01.png'),
   ```
   （このファイルへの追記は私（Claude）に頼んでもOK。「afterstudy に N枚入れた」と言ってください）

## メモ
- いまは仮に既存イラスト（書斎の間・桜）を表示しています。専用画像が入り次第そちらへ切り替えます。
- 画像は**アプリ同梱**（バンドル）です。増やしすぎるとアプリ容量が増えるので、まずは数枚〜十数枚から。
