# JLPT聴解 作問・音声 量産パイプライン

聴解問題を**公式音声のモーラ数・話速に寄せて**量産する全手順。正本Excel＝`問題\聴解.xlsx`。音声＝`問題\audio\<level>\<n_区分>\<id>.mp3`。旧版データ（旧audio・旧聴解.xlsx等）は`問題\old\`へ退避済み。

## 0. 区分とID
聴解C・学習区分記号：課題理解=K / ポイント理解=P / 概要理解=G / 発話表現=H / 即時応答=S。ID＝`<level>-C-<区分>-<通番>`（例 `N5-C-K-001`）。
- レベル別の区分：N5/N4＝K,P,H,S(4区分) / N3＝K,P,G,H,S(5区分)。

## 1. Excelの構成（21列・シート＝区分×レベル）
各シート：行1=メタ / 行2=注記 / 行3=ヘッダ / **行4＝JLPT公式(参考)行** / 行5以降＝作成問題。
列順（21列）：
`ID | 大問形式 | 場面・状況(導入) | スクリプト(台本) | スクリプト(ラベル除去) | 字数(ラベル除く) | モーラ数 | 本文秒数 | 速度(モーラ/秒) | 話者 | 設問 | 選択肢1(正解) | 選択肢2 | 選択肢3 | 選択肢4 | 正解 | 選択肢の提示 | 難易度 | 出題ねらい | 解説 | 備考`
- **モーラ数・本文秒数・速度は公式行・作成行とも必ず埋める**（量産の判断材料）。速度＝`モーラ数 ÷ 本文秒数`。
- 「スクリプト(ラベル除去)」＝D列から話者ラベル（`男（先生）：`等）を除いた本文。字数・モーラはこの列から数える。
- 保存前に**Excelで開いていないか確認**（`~$聴解.xlsx` ロックが在れば「閉じて」と依頼）。

## 2. 台本の作法（量産ルール）
1. **ボーダーレス（個人名なし）**：役割ベース（先生/学生・店員/客・部長/社員・同僚・母/息子・男の人/女の人 等）。固有名詞・人名は使わない。［[content-borderless-no-names] 方針］
2. **漢数字を使う**：`20`→`二十`、`9時半`→`九時半`。理由＝モーラを正しく数えられる（pykakasiはアラビア数字を読まず0モーラになる）＋TTSも自然に読む。
3. **質問の構造（重要）**：
   - **課題理解・ポイント理解**＝質問を**スクリプトの前後で2回**（場面ナレ内に1回＋設問列に1回）。
   - **発話表現・即時応答・概要理解**＝質問は**1回**。
4. **話者は最大2名**（Geminiの多話者TTS制約）。ラベルは`男（役割）：`/`女（役割）：`で**性別を明示**（TTSの声と一致／イラストとも一致）。
5. **長さは公式に寄せる**（モーラ目安）：N4課題≈200・N4ポイント≈120・N3課題≈140・N3ポイント≈170・概要≈160。多少ズレてOK（速度を合わせるのが主目的）。

## 3. 区分別の「本文（音声で流れる部分）」と選択肢
- **課題理解／ポイント理解**：本文＝2話者の**会話**。選択肢は印刷（`イラスト４択`/`文字４択`）＝音声には流れない。
- **概要理解**：本文＝1話者の**独話**。設問＋4択は最後に音声で流れる（選択肢列に記載）。
- **発話表現**：本文＝**状況ナレーション「（状況）。何と言いますか。」**（選択肢ではない！）。3択は音声で流れる（選択肢列）。イラスト併用。
- **即時応答**：本文＝最初の**投げかけ1文**。3つの応答が音声で流れる（選択肢列）。
- ※発話/即時の「本文秒数・速度」は**状況ナレ／投げかけ**を対象に測る（選択肢ではない）。

### 音声選択肢の連結（発話/即時/概要・本番形式）＝「永続番号クリップ＋同声で選択肢を個別生成」（Chirp3確定）
**選択肢が音声で流れる区分**は、本文の後に「番号→選択肢」を連結。
- **番号＝永続再利用クリップ（原速・毎回生成しない＝安定）**：`audio\_numbers\Chirp3-<声>\1..4.wav`（いち/に/さん/よん）。検証済み声＝**男Charon/Fenrir/Orus/Puck・女Aoede/Kore/Leda**（声を使い分け可）。
  - 作成法：①1文「`いち。に。さん。よん。これでおわりです。`」を生成→`silencedetect`で5分割→頭4つ。②分割が結合/過分割する声は**1つずつ個別生成**（尺≥0.28sを満たすまで再生成）。**検証＝4クリップを0.5s間で連結→Flash文字起こしで「1 2 3 4」確認**（※単一の短クリップを文字起こしすると誤認するので不可。必ず連結クリップで）。
- **選択肢＝番号と同じ声で個別生成**（**Chirp3=Cloud TTSは個別短文でも崩壊しない**＝Geminiと違う）→各選択肢を**resample**（レベル別倍率）。番号と選択肢は**必ず同一話者**。
- **連結**：`本文(resample) →1.2s→ 番号(原速) →0.3s→ 選択肢(resample) →0.5s→ 番号 →0.3s→ 選択肢 …`。概要は本文の後に **設問→（番号→選択肢）**。間の秒数は無音PCM挿入で固定（調整可）。
- **必ずFlash文字起こし検証**：番号1/2/3(/4)＋選択肢が全部揃うか確認してから採用。
- ※**Geminiで作る場合**は個別短文/番号なし一括が崩壊するため「番号インライン一括（`いち、{選1}。に、{選2}。`）＋選択肢1文正規化＋大きい無音上位3の先頭2で分割＋検証」が必要。**Chirp3なら個別生成でよい**（崩壊しない）。
- 本文・選択肢はマスター保存→**速さ(resample)・間の再調整はTTSなし＝無料**。Excelの本文秒数・速度は本文のみの値。
- ※`audio\_numbers\Charon|Leda\` の番号クリップは原速参照用に保持（この方式では未使用）。

## 4. モーラ数の数え方
`pykakasi`で読み(ひらがな)に変換→拍を数える。アラビア数字が残る場合のみ`num2words(lang='ja')`で読みに変換してから数える（台本は漢数字推奨なので基本不要）。
- 小書き拗音（ゃゅょぁぃぅぇぉゎ）＝直前と合わせて**0**（加算しない）。
- 促音っ・撥音ん・長音ー＝**各1モーラ**。
```python
import pykakasi; kks=pykakasi.kakasi(); NON_MORA=set('ゃゅょぁぃぅぇぉゎ')
def mora(t):
    c=0
    for ch in ''.join(s['hira'] for s in kks.convert(t)):
        if ch=='ー': c+=1
        elif 'ぁ'<=ch<='ん' and ch not in NON_MORA: c+=1
    return c
```
- **誤読に注意（要スポット確認）**：助数詞・同音異義でpykakasiが外すことがある。実例＝「今日は」→こんにちは(誤,5)／正＝きょうは(3)。怪しい語は読みを目視確認し、必要なら手修正。

## 5. 音声生成＝「ゆっくりTTSでマスター生成→atempoは“速める”側だけ・番号はクリップ挿入」（確定方式）
**Gemini TTS**：`gemini-2.5-pro-preview-tts`（高品質）／`gemini-2.5-flash-preview-tts`（**約半額**・量産向け、質は試聴で判断）。**声は固定しない＝役割・問題に応じて様々な声を使ってよい**（男女・複数可）。候補例：男`Charon`/`Fenrir`/`Puck`、女`Leda`/`Aoede`/`Kore`等。**1問内（本文＋番号＋選択肢）は基本同一話者**で揃える。会話は男女で割当。会話＝multiSpeaker／発話・即時・概要の本文＝single voice。
- **(1) マスターは「少しゆっくり」TTSで生成**：プロンプト先頭に `少しゆっくり、はっきりと読んでください。` ＋改行を付け、**クリーンなスロー音声（≈N5の速さ）**を作る。生成直後PCMを`audio\<level>\_master\<id>.wav`へ保存。
  - **重要**：**atempoで“遅くする”と声が荒れる（金属音）＝禁止**。スローは必ず**TTS側（少しゆっくり指示）**で作る。「ゆっくり」だと効きすぎて遅すぎ＝「少しゆっくり」が基準。
- **(2) 速さはatempoで“速める”側だけ調整**：マスター＝N5速度（最も遅い）。**N5はマスターそのまま**。**N4／N3はレベルが上がるほど atempo>1.0 で少し速める**（**速める方向は声が荒れにくい**／いずれも“普通”より遅い）。目標モーラ/秒から `目標尺=mora/目標速度`、`atempo=実尺/目標尺`。
- **(3) 番号は保存クリップを挿入**（§3参照）。**選択肢は番号なしで生成**して連結。
- **やってはいけない（失敗済み）**：①atempo<1の強いスロー＝間延び/声荒れ。②「ゆっくり」指示は文長で効き方がバラつく→**マスターごとにatempoで目標速度へ正規化**。③数字のみ/極端に短い1文のsingle TTS＝**空応答**（番号は§3の専用法で）。
- 稀に`candidates[0]`に`content`無し空応答→**再試行**。429は指数バックオフ。「間」は無音PCM挿入で作る（話速は触らない）。マスター保存済みなら**間・速さの再調整はTTSなし＝無料**。

```python
# 生成→マスター保存→atempoで最終mp3（要点）
speech={'multiSpeakerVoiceConfig':{'speakerVoiceConfigs':[{'speaker':lab,'voiceConfig':{'prebuiltVoiceConfig':{'voiceName':v}}} for lab,v in voices]}}
body={'contents':[{'parts':[{'text':dialogue_with_labels}]}],'generationConfig':{'responseModalities':['AUDIO'],'speechConfig':speech}}
# → PCM(L16/24k)→ wave保存(master.wav) → ffmpeg atempo=<rate> → mp3 → ffprobeで秒数→ 速度=mora/秒
```
- Gemini APIキーはスクリプト内（既存tts系と同一）。ffmpeg/ffprobeはPATH。

## 6. 公式参考行（手本）の作り方
1. 公式問題例音声を**Gemini Flashで文字起こし**（`gemini-2.5-flash`、audio inline）。出典明記・私的参照（商用コピー/同梱不可）。
2. **タイムスタンプで本文区間を実測**：場面ナレ・設問・無音を除いた「会話/独話/投げかけ」の開始秒・終了秒→**本文秒数**。速度＝mora÷本文秒数。
   - 短い非対話（発話/即時）はGeminiのセグメント尺が外れやすい→**個別に開始/終了秒を測り直す**（過去に2.6s誤り→実測6.1sの例あり）。
3. 列割り：C=場面状況／D=本文（会話/独話/投げかけ）／設問列／選択肢列（**音声で流れる選択肢は文字起こしして記載**：発話/即時/概要）。**アラビア数字は漢数字へ**統一しモーラ再計算。

## 7. コスト・後始末
- 有料API＝Gemini Pro TTS（会話1本≈2円）/ Flash文字起こし（数音声で1円台）。**1000円超は事前見積→承認**。使用後は**モデル名＋実費を報告**（円換算）。
- 倍率変更・休止調整・atempoはローカル＝**追加課金なし**。
- テスト用の一時音声/中間wavは確認して削除。マスターwavは保持（再rate用）。

## 8. 標準手順（量産1問あたり）
1. 台本を作法どおり起こす（漢数字・ボーダーレス・質問構造・2話者）。
2. Excelに作成行を追記、ラベル除去列・字数・モーラを算出。
3. TTSで自然生成→マスター保存→**レベル別atempo**で最終mp3。
4. 速度＝mora÷秒 をExcelに記入（公式行と並べて差を確認）。
5. 公式行（手本）も同シートに用意（§6）。実費報告。
