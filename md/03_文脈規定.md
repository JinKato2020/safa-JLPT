# 03_文脈規定（③文字・語彙）

> **問数**: N5=10問 / N4=10問 / N3=11問（公式仕様）。※N4教材サンプルはQ13–20の8問だが本番は10問。
> **測る面**: 空所に合う語を**選ぶ**（意味×共起）。①②は語が文中に既在、③は**語そのものを選ぶ**＝意味運用へ移行。類義語を**文脈（共起）で1つに絞る**。
> **品質規律（全大問共通）は 00_共通情報.md の 第IV部・第V部 を必ず参照。** ここは③文脈規定固有の作り方のみ。
> **一意性が壊れやすい大問か**: **壊れやすい**（近い選択肢を文脈で1つに絞る本質。監査の重点）。

---

## 公式の形式（レベル別ダイジェスト）

- **指示**: N4「（　）に なにを いれますか。」／ N3「（　）に入れるのに最もよいものを…」
- **形式**: 1文（N4は会話体もあり）の空所（　）に**文脈上いちばん合う語**を4択（名詞/動詞/形容詞/副詞/カタカナ/N3はオノマトペ）。**全語が単体では実在する級内語で、文脈でだけ一意化**。
- **級差(語彙)**: N4=基本漢語（予約/招待）・和語動詞・時の副詞。**N3=抽象名詞（欠点/短所/不満/不足）・類義動詞（延長/延期/停止/休止）の弁別が増える**・受身・擬態語・カタカナ。
- ※ダミーの手口・鍵・級差(形式)・アプリ差・作問手順は下の「作問ガイド」に集約。

## 出題意図・作問ガイド（N4 / N3）

> **公式PDFを実読して抽出（2026-07-17）**。N4=もんだい3 問13〜20（8問）／N3=問題3 問15〜25（11問）。
> ※公式PDFは「問題例」＝**抜粋**。N4は8問しか載っていないが本番は10問（本番数の正本＝`app/src/data/examBlueprint.ts`）。

### 出題者の狙い（実読して分かった核心）

**「語を知っているか」ではなく「文中の鍵1つに反応して、似た語の中から1つに絞れるか」。**

公式は必ず **2段階**で作られている。
1. **4語を何らかの軸で揃える** → 分野・品詞・語形では消せなくする（＝当てずっぽうを封じる）
2. **文中に鍵を1つだけ置く** → その鍵だけが正解を一意にする

**この2段階が文脈規定の全て。**「揃える」を怠ると当てずっぽうで解け、「鍵」を怠ると複数正解になる。

### ダミーの手口（実読20問の実測内訳）

| # | 手口 | 公式の実例（選択肢の並び） |
|---|---|---|
| 1 | **語形をそろえる**（語頭・語末）＝**40%** | 全部「〜なかった」／全部「〜られた」受身／全部「で〜」で始まる複合動詞／全部4拍の擬態語 |
| 2 | **同一意味フィールド** | 予約・約束・計画・予定（全部「先を決める」）／泊まる・住む・勤める・引っ越す（全部「場所に居る」）／そろそろ・さっき・このごろ・しばらく（全部「時の副詞」） |
| 3 | **同じ漢字を共有する漢語**＝**20%** | 延長・延期／停止・休止 ｜ 無用・無駄・無理 ｜ 気温・体温・温度 |
| 4 | **音が近い near-miss を必ず1つ** | しょうかい↔しょうたい ／ われて↔わかれて ／ あきなかった↔あきらめなかった |
| 5 | **選択制限**（何と結びつくか） | 爪が「割れる」（壊れる=機械／破ける=紙） |
| 6 | **全部が話題に関連＝分野で消せない**（最難） | 「子どもの成長」に対し 栄養・経験・環境・教育（**4つとも成長に関係する**。決め手は「バランスよく**取る**」だけ） |

**手口6が公式の最高到達点**。分野・品詞・語形すべてで消せず、**コロケーション1点だけ**で切る。

### 鍵（正解を一意にする決定打）の型

| 型 | 公式での置かれ方 |
|---|---|
| **コロケーション** | 「チケットを」→予約 ／「バランスよく取る」→栄養 ／「〜を測った」→体温 |
| **因果・論理** | 「なくしてしまったので」→謝る ／「つらいときもあったが、最後まで」→諦めない ／「大雨で」「1週間後に」→延期 |
| **時間の向き** | 「あと15分」「行きましょうか」→そろそろ（＝これから。さっき/このごろは過去向き） |
| **恒常↔一時** | 「あそびに行くとき」「ホテルに」→泊まる（住む/引っ越す＝永続で矛盾） |
| **場面の限定** | 「結婚式に」→招待（紹介ではない） |

**鍵は必ず1つ。**2つ置くと簡単になり、0だと複数正解になる。

### 級差（形式面）

| | N4 | N3 |
|---|---|---|
| 表記 | **分かち書きあり**・ひらがな中心・漢字にルビ無し | 分かち書き無し・**漢字＋ルビ**（N3超の漢字と選択肢の漢語にもルビ） |
| 語彙 | 和語動詞・イ形容詞・基本漢語（予約/招待）・時の副詞 | **漢語名詞が主力**（5/11）・受身形・擬態語・カタカナ・複合動詞 |
| 鍵 | やや明示的（「チケットを」） | 1語だけ・抽象的（「バランスよく取る」） |
| 特殊形式 | **会話形式あり**（A「…」B「…（　）…」） | 見られず |
| 指示文 | 「（　）に なにを いれますか。1・2・3・4から いちばん いい ものを ひとつ えらんで ください。」 | 「（　）に入れるのに最もよいものを、1・2・3・4から一つえらびなさい。」 |

### アプリの現行データとの差（実測 2026-07-17・3,413問）

| 指標 | 公式(20問) | アプリN5 | アプリN4 | アプリN3 |
|---|---:|---:|---:|---:|
| 4語の文字種がそろう | **90.0%** | 42.1% | 69.3% | 85.8% |
| 語末1字がそろう | **40.0%** | 13.5% | 13.8% | 10.3% |
| 漢字を共有する語あり | **20.0%** | 6.5% | 7.2% | 12.7% |

**現行の弱点（無作為抽出で確認した実例）**
- **荒唐無稽ダミー**が残る: 「友だちに〔電話〕をかけます」の誤答が **さかな・ほん・いす** ／「人を〔先生〕といいます」の誤答に **石鹸**。**分野違い＝当てずっぽうで消せる＝測定にならない**（共通原則2の違反）。
- **誤答の向きが揃いすぎ**: 「犬が死んで〔悲しい〕」の誤答が うれしい・楽しい・おもしろい＝**全部プラス感情で3つ同時に消える**。公式なら さびしい/つらい/くやしい と**同じ向き**で寄せる。
- **手口3（同漢字語形）がほぼ無い**: 公式の主力（延長/延期・無用/無駄/無理）がN5/N4で7%以下。
- **手口6（全部関連＋コロケーションで切る）が事実上ゼロ**。

**良い実例もある**（この型を増やす）: 「あさからばんまで はたらいて、ちょうど〔一日〕でおわった」誤答=一週間・一か月・一年（全部期間＝手口2＋鍵「あさからばんまで」）／「大きな地震で、古い家が〔倒れる〕」誤答=焼ける・冷える・濡れる（全部被害の自動詞）／「天気予報はよく〔外れる〕」誤答=生まれる・疲れる・慣れる（全部「〜れる」＝手口1）。

### 作問の手順（この順で書く）

1. **語を決める**（レベル内の語彙から）
2. **鍵を1つ決める**（コロケーション／因果／時間の向き／恒常↔一時のどれか）
3. **鍵が効く文を書く**（役割ベース・個人名なし）
4. **誤答3個を、手口1〜6のどれかで揃える**（**必ず1つは near-miss**）
5. **一意性テスト**: 誤答を1つずつ空所に入れ、「日本人がこの文を言うか」を見る。少しでも言えたら**第2の正解＝不可**
6. 揃えると一意にできない時は、**手口を1段ゆるめる**（6→2）。**第2の正解を作るくらいなら易しくする**

**禁止**
- 荒唐無稽な分野違いダミー（当てずっぽうで消せる）
- 誤答が3つとも同じ向き（1つの理屈でまとめて消える）
- 鍵を2つ以上置く（簡単になる）／鍵ゼロ（複数正解）
- 個人名（役割ベースで書く）

**難易度操作**: 手口を上げる（2→3→6）ほど難。鍵を弱める（明示的な目的語→抽象的な共起動詞）ほど難。**範囲外の語で難しくしない**。

## ③-N5 文脈規定（公式10問）

> **実読**: `問題作成の参考/N5_漢字語彙.pdf` もんだい3＝**10問**(21〜30)。

指示文: 「（　）に **なにが はいりますか**。」

### 狙い

**ここだけクロスではない。** N5文脈規定の設計は第I部③と同じ「**揃える＋鍵1つ**」だが、**揃え方の徹底度が桁違い**。

**実読10問中10問（100%）が、4択とも品詞・語形が完全に一致している。**

| 問 | 4択の揃え方 |
|---|---|
| 21 | 全部**助数詞**（階/本/冊/台） |
| 22 | 全部**て形の他動詞** |
| 23 | 全部**持ち物の名詞** |
| 24 | 全部**な形容詞** |
| 25 | 全部**カタカナの場所** |
| 26 | 全部**学習系の漢語サ変**（質問/勉強/練習/授業） |
| 27 | 全部**部屋にある物** |
| 28 | 全部**「〜ました」の動詞** |
| 29 | 全部**い形容詞** |
| 30 | 全部**て形の自動詞** |

つまり**N5では「品詞で消す」が絶対にできない**。第I部の手口1（語形をそろえる）が、N4の40%に対し**N5は100%**。

**鍵の型**（10問中の内訳）:
- **「〜から／ですから」で理由を明示 → 結果を選ばせる**＝**4問(40%)**。N5最大の鍵。「時計を忘れた**から**、時間が分からない」「駅に近い**ですから**、便利」「暑い**ですから**、窓を開ける」「砂糖をたくさん入れた**から**、甘い」
- **コロケーション**＝6問。「ナイフで切る」「風が吹く」「漢字を覚える」「プールで泳ぐ」

**N5の鍵は必ず文中に明示される。** N3のように「バランスよく取る」1語で抽象的に切らせることはしない。**「〜から」で因果を接続詞として見せる**のがN5の作法。

### 受験者のどの弱点を突いているか

- **助数詞**: 日本語最大の初期難関。階/本/冊/台/枚/人 の使い分けは母語に対応物が無い。
- **動詞のコロケーション**: 「風が吹く」を「風が走る」と言ってしまう（母語の直訳）。
- **因果を追う体力**: 「〜から」の前を読んで後ろを決める、という**2節にまたがる処理**。N5では語彙より**この処理そのもの**が難所。
- **漢語サ変の微差**: 質問/勉強/練習/授業 は全部「学校でやること」で、分野では切れない。

### アプリ実装・現行データとの差（実測 2026-07-17）

| 指標 | 公式10問 | アプリN5(672問) |
|---|---:|---:|
| 4択の品詞・語形が完全に揃う | **100%** | 上表の実測で **42.1%**（文字種ベース） |
| 誤答が正解と字を共有しない（＝分野違いになりやすい） | 低い | **61%** |
| verified（作り直し済み） | — | **0問**（N5は未着手） |

**N5文脈規定672問は、検証がまるごと未着手**（`daimon.ts` の `CTX_GATED_LEVELS` はN4/N3のみ。N5は全部そのまま出題中）。

**良い実例**（この型を増やす）: 「部屋には誰もいなくて、〔一人〕でした」誤答＝一つ・一本・一まい＝**全部助数詞で揃う**＝公式21と同型。／「空に〔黒い〕雲が出てきて、今にも雨がふりそうです」誤答＝白い・赤い・青い＝**全部色のい形容詞**＋鍵「雨がふりそう」。

**この2問は公式と同じ品質。N5にはすでに良い型が存在するので、ゼロから作る必要はなく「揃っていない問題を揃え直す」作業になる。**

### 作問の手順（N5文脈規定）

1. **品詞を1つ決める**（助数詞／て形動詞／い形容詞／な形容詞／カタカナ名詞／漢語サ変）
2. その品詞から**N5内の実在語を4つ**選ぶ（**必ず同じ品詞・同じ活用形**）
3. **鍵を1つ置く**。N5は **40%を「〜から／ですから」の因果**にする（残りはコロケーション）
4. 分かち書き・ルビ無し・役割ベース
5. 一意性テスト（本ファイル「作問の手順（この順で書く）」手順5と同じ）
