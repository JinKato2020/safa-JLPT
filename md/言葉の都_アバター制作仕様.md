# 言葉の都・アバター制作仕様（AI画像生成用）

広場に立つ「他の学習者」を表すプリセットアバター **10体（男子 m1〜m5 / 女子 f1〜f5）**。
出力は `画像\キャラクター\avatars\<code>.png`（例 `m1.png`）。差し替えは `src/plaza/avatars.ts` の `image` に `require(...)` を入れるだけ。

## 共通スタイル（10体で必ず統一）
- **画風**：やわらかい和紙調のフラットイラスト。既存の桜マスコットと同じ空気感（淡い・親しみやすい・線は細め）。アニメ寄りでリアル調にしない。
- **構図**：全身・正面やや斜め・直立の基本ポーズ（広場を歩く/座るに転用できる中立姿勢）。足元まで入れる。
- **背景**：**完全透過（アルファ付きPNG）**。影は付けない（描画側で丸影を足す）。
- **サイズ**：正方 **512×512** 目安、余白は上下に均等。10体で頭身・目線の高さ・線の太さ・彩度を揃える。
- **中立・ボーダーレス**：特定の国・民族を示す記号を付けない（国旗は別に表示する）。肌・髪の色は自然にばらけさせて多様性を出すが、民族ステレオタイプにしない。
- **雰囲気**：勉強を楽しむ穏やかな笑顔。小物は控えめに（本・ペン・カバン程度、無くても可）。武器・ブランド・文字・ロゴは入れない。

## 10体の作り分け（差別化の目安）
男子 m1〜m5・女子 f1〜f5 で、髪型・服の色・小物を変えて「10人いる」と分かるように。

| コード | 目安（髪・服・小物のイメージ。厳密でなくてよい） |
|---|---|
| m1 | 短髪・紺のパーカー・リュック |
| m2 | くせ毛・グレーのカーディガン・本を1冊 |
| m3 | すっきり黒髪・白シャツ＋カーキ・眼鏡 |
| m4 | 明るい茶髪・ボーダーT・手ぶら |
| m5 | 少しラフ・緑のジャケット・ノート |
| f1 | ロング・淡いピンクのワンピース |
| f2 | ボブ・水色のセーター・トートバッグ |
| f3 | ポニーテール・生成りのブラウス・本 |
| f4 | 巻き髪・黄色のカーデ・眼鏡 |
| f5 | まとめ髪・和風スカーフ／ショール |

## 生成プロンプト（英語・そのまま使える雛形）
各体でこの雛形の `{...}` を差し替える。10体まとめて「同一スタイル・同一構図」を強調。

```
A soft washi-paper style flat illustration of a friendly young language learner, full body, standing front-facing three-quarter pose, gentle smile, {hair}, {outfit}, {small prop or none}, muted warm pastel palette, thin delicate outlines, cozy Japanese stationery aesthetic, no text, no logo, no national symbols, transparent background, centered, consistent character-sheet style, 512x512.
```

- スタイルを揃えるコツ：1体を「基準」に作り、以降は「same art style, same proportions, same line weight as the reference」を付けて生成する。

## 参考：広場の背景（後工程・別素材）
アバターとは別に、広場の背景1枚も必要（同じ和紙調）。桜の木・小さな噴水や井戸・ベンチ・石畳の広場・柴犬。人物は含めない（アバターを上に重ねる）。横長で上部が空、下部が広場の地面。※これは第2段。まずアバター10体を優先。
