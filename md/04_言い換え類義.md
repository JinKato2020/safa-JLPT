## 公式の形式（レベル別ダイジェスト）

- **★形式が級で違う**: **N4＝文レベル**（提示文→ほぼ同義の4文）、**N3＝語レベル**（下線語→意味が最も近い4語）。同じ大問名だが選択肢の単位が違う。
- **指示**: N4「＿＿の ぶんと だいたい おなじ いみの ぶんが あります。」／ N3「＿＿に意味が最も近いものを…」
- **形式**: N4=提示文（下線語つき1文）→ほぼ同義の文を4択（周辺枠は共通・下線語の言い換えだけ変わる・12〜22字）。N3=下線語（1語〜句）→意味が最も近い語を4択。**N3は硬め・抽象の語**（骨折する→ほねをおる、くさった→わるくなった、流行→はやる）。
- ※狙い・ダミー設計・一意性・難易度・類題は下の「作問ガイド」に集約。

## 出題意図・作問ガイド（N4 / N3）

> **最重要**: **N4＝文レベル**（提示文→ほぼ同義の**4文**）、**N3＝語レベル**（下線語→意味が最も近い**4語**）。同じ大問名だが**選択肢の単位が違う**。

### N4（文レベル）
**形式**: 例題**文（下線語つき）→ ほぼ同義の4文**。周辺の枠は共通、下線語の言い換えだけが変わる。
**文長**: 公式と同程度に**短く**（提示文・選択肢とも概ね12〜22字）。無駄な修飾で長くしない。
**狙い**: キー語の意味を**文まるごと**の同義に置換できるか。
**ダミー設計**: キー語を ①正しい同義 ②意味がズレる近接語 ③上位/下位語のズレ で崩した"別の文"。
**一意性の担保**: 同義文を**1つだけ**にし、他は「一部だけ重なるが全体では意味が違う」文に。
**難易度操作**: キー語を動詞句・複合語（ふくしゅうする＝ならったことをもう一度べんきょうする）にすると難。

**オリジナル類題**
- 例1: 会議は 来週に のびました。 → 1 会議は 来週に なりました。 2 中止に なりました。 3 短く なりました。 4 長く なりました。 → **1**（のびる＝延期）
- 例2: 店員に 道を たずねました。 → 1 おしえました 2 **ききました** 3 つくりました 4 わたりました → **2**

### N3（語レベル）
**狙い**: 下線語（1語〜句）の**同義理解**。N3は硬め・抽象の語。
**ダミー設計**: ①近接だがズレる語 ②反対/上下関係のズレ ③連想の罠。**同一意味フィールド・同一品詞で揃える**。

**オリジナル類題**
- 例1: 仕事が＿たまって＿いる。 1 たくさん残って 2 早く終わって 3 少なくなって 4 なくなって → **1**（2・4は反対、3はズレ）
- 例2: 食事の＿作法＿は、子どものときに親から教わった。 1 **礼儀** 2 しつけ 3 習慣 4 常識 → **1**（しつけ＝親が子を訓練する行為で作法そのものでない＝連想の罠）

### ★言い換えの一意性が壊れる実例（2026-07-17 実測・必ず避ける）
**形式によらず、非一意は約8%発生する**（本走行の実測）。

| 形式 | 非一意率（本走行） | 参考: パイロット5問 |
|---|---|---|
| **N4=文レベル** | **8.6%**（16/185） | 0%（5/5一意） |
| **N3=語レベル** | **7.3%**（11/150） | 40%（2/5非一意） |

> **⚠️ パイロットの数字（N4=0%／N3=40%）から「文レベルは構造的に安全・語レベルは危険」と結論するのは誤り。**
> 5問という小標本の偶然に理屈を後付けしたもので、本走行では**両形式ともほぼ同率**だった。
> **教訓: 5問の結果で率を語らない。パイロットは"作り方の検証"には有効だが、"率の推定"には使えない。**（→ 00_共通情報.md 第IV部 規律1）

**実際の失敗例（プロンプトに必ず埋める）**
- **刷った**→正解「印刷する」に誤答「**コピーする**」…「ポスターを百枚コピーした」は自然で意味が重なる＝**第2の正解**
- **活気**→正解「活力」に誤答「**熱気**」「**エネルギー**」…「町は熱気にあふれていた」も成立＝**3つ正解**
- **大抵**→正解「だいたい」に誤答「**いつも**」（N4文レベルでも同じ事故が起きる）
- **出版**→正解「刊行」に誤答「**販売**」…「辞書を販売した」が成立（**修理段が作った**第2の正解）
- 教訓: **自分が確定した正解の近縁語を誤答にするな**。同義語が密集する語（活気＝活力/元気/勢い/にぎわい…）は**誤答を6→5→4に減らす**方が正しい。

> **公式N5＝文レベル**（提示された**文**に対し、ほぼ同義の**4つの文**から選ぶ）。**N4と同形式**。
>
> **アプリN5＝語レベル**（下線語に近い**語**を4語から選ぶ）＝**N3形式**。**93問すべてが誤った形式**（実測 2026-07-17: `synonym_N5.json` の stem 保有＝0/93）。

| | 公式 | アプリ現行 |
|---|---|---|
| N5 | **文レベル** | **語レベル** ← **不一致** |
| N4 | 文レベル | 文レベル（185問・stemあり）✓ |
| N3 | 語レベル | 語レベル（1000問）✓ |

**修正方法はデータ側だけで済む。** `app/src/data/daimon.ts` の分岐は **`sy.stem` の有無**で文レベル/語レベルを自動で切り替えている（`if (sy.stem)` → 「だいたい同じ意味の文はどれですか。」）。したがって **N5の93問に `stem`（提示文）を持たせ、`choices` を文にすれば、UIコードは1行も触らずに公式形式になる**。

### 狙い

**「同じ内容を別の言い方で言えるか」＝語彙の網の目。** N5では特に以下の4型。

| 型 | 何を測るか | 誤答の作り方 |
|---|---|---|
| **上位語↔下位語の分解** | 両親＝父と母 | **同じ関係の別ペア**（祖父母／兄弟／姉妹）＝全部が家族ペアで揃う |
| **形容詞の言い換え** | やさしい＝かんたん | **全部が評価の形容詞**。うち1つは**正解の対義語**を置く（near-miss） |
| **動詞の言い換え** | せんたくする＝あらう | 同じ目的語（服）を取る**別の動詞**を3つ（ぬぐ/わたす/きる） |
| **反対語の否定＝クロス** | くらい＝あかるくない | **{あかるい, しずか} × {肯定, 否定}** の交差 |
| **授受の視点転換＝クロス** | AがBに貸した＝BがAに借りた | **{主語の向き} × {貸す/借りる}** の交差 |

**最後の2つがN5言い換えの山場。**
※ただし「どちらも2×2クロス」は**誤りだった**（下記「実走行で分かったこと」参照）。
`negation_cross` は 2×2 だが、`perspective_cross` は 2×2 ではない。

### ★実走行で分かったこと（2026-07-17夜・160問の作り直しで）

#### (1) `perspective_cross` は 2×2 クロスではない（**設計の根本誤り**）

授受・貸借・売買の動詞では、**4セルが「2つの出来事」にしか対応しない**。
1つの出来事に対し「貸す視点」と「借りる視点」の**2つの言い方が必ず同義**だから。

```
{主語の向き} × {貸す, 借りる} ＝ 4セルに見えるが…

  先生が学生に貸した  ┐ 本が 先生→学生 に動く   … stem
  学生が先生に借りた  ┘ ＝【同一の出来事】       … 正解（だから正解になる）

  先生が学生に借りた  ┐ 本が 学生→先生 に動く
  学生が先生に貸した  ┘ ＝【同一の出来事】       … 互いに同義＝両方は置けない（規律7）
```

| 誤った指示 | 起きること |
|---|---|
| 「誤答＝残り3セル」 | 3個目が **stem 自身**＝100%の第2の正解（パイロット3問全部で発生） |
| 「残り2セルを両方誤答に」 | 互いに同義＝受験者が論理だけで両方消せる → **正解と近接動詞の実質2択に退化**し、**向きを測れなくなる** |

**確定した作り方**（誤答ちょうど3個）:

```
stem : 先生が 学生に 本を 貸しました。
正解 : 学生が 先生に 本を 借りました。
誤答 : 学生が 先生に 本を 貸しました。   ← 逆向きの出来事【2つの言い方のうち片方だけ】
誤答 : 学生が 先生に 本を 返しました。   ← 近接動詞（同じ分野＝物の受け渡し）
誤答 : 先生が 学生に 本を 見せました。   ← 近接動詞
```

`negation_cross` にこの欠陥は**無い**。**stem（くらい）が交差の外にある**ため、
`{対義語, 別の形容詞} × {肯定, 否定}` の3セルが素直に取れる。

#### (2) `negation_cross` の採否 — 4類型は作れない（候補71語中29語を却下＝41%）

**採用できるのは「1本の物差しの両端」だけ。** 否定が反対側に確実に落ちるから（狭い/広い・長い/短い・大きい/小さい）。
※ただし**両端であることは必要条件にすぎない**。その軸に**中間の語彙**があると両端でも成立しない
（**寒い/暑い は反証で `bad_answer` になった**＝中間が「暖かい・涼しい」として語彙化されているため。→ 下記(6)）。

| 却下する類型 | 理由 | 実例 |
|---|---|---|
| **多方向の語** | 物差しが1本でない。否定が一点に定まらない | 色（黒い→「白くない」は赤も青も含む）・青い・赤い・黄色い |
| **物差しの中間語** | 否定が両側を含む | 涼しい（「暑くない」は寒いも含む）・温い・暖かい |
| **「〜じゃない」が婉曲になる評価・感情語** | 否定＝控えめな肯定になり等価でない | **好き（「嫌いじゃない」＝特に好きではない）**・上手（「下手じゃない」＝普通）・大好き・元気（「病気じゃない」は疲れも含む） |
| **両立しうる語対／対義語が級外** | 排他的でない／N5に無い | 甘い⇔辛い（「甘辛い」で両立）・便利（不便＝N4）・本当（うそ＝N4）・有名・若い・欲しい・痛い |

**判定の一言**: 「同一軸上の**排他的**対義か（同時に成立しないか）」。3段階以上ある軸（暑い/暖かい/涼しい/寒い）は不可。
※例外的に **嫌い→好きじゃない は採用**（婉曲として定着しており逆向きには効く）。

**2軸目（上例の「静か」）の禁止事項**:
- **正解と因果・含意で結びつく軸は不可**（実例: 安い野菜 の2軸目に「新しい」→「新しくない＝古い＝安い」を連想／
　速い電車 に「新しい」→「古い＝遅い」／多い学生 に「静か」→「多い≒静かじゃない」／大人 に「学生」→「学生じゃない＝大人」）
- **正解の対義語と同じ活用型**にする（い形容詞／な形容詞。割れると否定形の語形で正解が浮く＝規律8）
- かな表記が多義になる語は**漢字＋ルビで固定**（かぜ→風/風邪、かみ→髪/紙/神）

N5の425組のうち、**言い換えに使えるのは約114組**。93問はほぼその天井まで使い切っていた＝**過去の選別は妥当だった**。

| 却下理由 | 組数/例 |
|---|---|
| 答えがN3語 | 138組（高価・直ちに） |
| 答えが辞書に無い（死語・級外） | 173組（**感冒**←かぜ・**乳酪**←バター） |
| 読みが同じ（同音異字・表記違い） | 暑い/熱い・在る/有る・降りる/下りる |
| 自他ペア | 開く（あく）／開ける（あける） |
| 品詞違い | 黄色い／黄色・泳ぐ／水泳・大きな／大きい |
| 助数詞の形違い | 一／一つ・五／五つ |

#### (4) 総数は「使える vocabId の数」で決まる（1語＝1問）

id は `sy:<vocabId>`、ユニットは `<vocabId>#synonym`。**同じ語で2問は作れない。**
→ 語ペアと `negation_cross` の候補が**重なる**（多い・上手・丈夫・大変は類義ペアかつ形容詞）。バッチを組む時に必ず排他にする。

**実測（2026-07-17）**: N5語彙723語／言い換えで使用済93語／空き630語。
空きのN5形容詞71語（→`negation_cross` は42問に着地）・授受8語すべて空き（→`perspective_cross` 8問）。
**上限は約160問**（既存93＋語ペア約20＋否定クロス42＋視点クロス8）。

#### (5) 型に `adv`（副詞・疑問詞）が要る

実データの**24問中7問が副詞・疑問詞**（ちょうど/ちょっと/どう/どうして/時々/とても/なぜ／もう／そして）。
`noun|adj|verb|hypernym` の閉じた型だと生成役が `adj` へ寄せるしかなく、
**`adj` に付いた「正解の対義語を1つ入れる」規則が副詞に適用されて非文になる**（もう→まだ が過去形と結べない）。
→ `adv` を型に足す。**「対義語を必ず1つ」は形容詞のみの規則**と明記する（大切/大事・大丈夫/平気にも対義語は無い）。

※判定は**主品詞＝posの先頭タグ**で行う。`'adv' in タグ列` で見ると
`朝['n','adv']`・午前・昼・夜・晩・所・近く・全部・大勢 まで副詞になる（実際に踏んだ）。
**副詞的用法がある名詞**と**品詞が副詞の語**は別物。

#### (6) `negation_cross` は「1本の物差しの両端」でも作れないことがある — **中間が語彙化された軸**

第(2)節の「採用できるのは1本の物差しの両端だけ」は**必要条件であって十分条件ではない**。

**反証で `bad_answer`（正解自体が不成立）と判定された実例**:

```
stem : この 家(いえ)は 寒(さむ)いです。
正解 : この 家(いえ)は 暑(あつ)くないです。   ← ★成立しない
```

**温度は「暑い/暖かい/涼しい/寒い」と4点に語彙化されている。** だから「暑くない」は中間帯（暖かい・涼しい・
ちょうどいい）を丸ごと含み、**「寒い」を一意に指さない**。生成役は「涼しい」を中間語として却下していたのに、
**同じ軸の両端である「寒い」は作ってしまった**（軸が汚染されていれば両端も汚染される）。

→ **判定は「両端か」でなく「その軸に中間の語彙があるか」**。
　 中間が語彙化された軸（温度）は**両端でも不可**。
　 成立する軸（実測）＝ 大きい/小さい・長い/短い・太い/細い・やさしい/むずかしい・きれい/汚い
　 （＝中間を指す単語が無い＝否定が反対側に落ちる）。

#### (7) 出す/入れる は `perspective_cross` にならない — **対義語であって視点転換ではない**

```
貸す/借りる・売る/買う・教える/習う → 1つの出来事を【二人のどちらから見るか】で動詞が替わる → 同義文が作れる
出す/入れる                        → 反対向きの【2つの別の出来事】＝ただの対義語   → 同義文が原理的に無い
```

視点転換は「**同じ出来事の別の言い方**」。対義語は「**別の出来事**」。
出す/入れるは `negation_cross` にもできない（「出さない」は「入れる」を意味しない）。
→ **N5の `perspective_cross` は6問が上限**（貸す・借りる・教える・習う・売る・買う）。
　 ※あげる/もらう/くれる は本アプリの語彙データのN5に**存在しない**（実測）ので使えない。

#### (8) 表層で正解が浮く — **153問中43問(28%)** に検出。3つの型で対処が違う

| 型 | 件数 | 例 | 対処 |
|---|---:|---|---|
| **A. 語形割れ** | 9 | 正解「広くないです」（**い**形容詞）に2軸目が「きれいじゃないです」（**な**形容詞）＝「〜くないです」が正解だけ | **直す**（2軸目を同じ活用型に） |
| **B. 字の共有** | 14 | **母→お母さん**・昼→昼間・服→洋服・道→道路・旅行→旅・女→女性・危ない→危険・所→場所 | **受け入れる**（下記） |
| **C. 属性不足** | 20 | 正解「トイレ」がカタカナだがカタカナ誤答が1個だけ／正解「学習します」が漢語サ変だが同型誤答が1個だけ | **直す**（同属性3個以上 or 誤答4個で2:2） |

**Bを受け入れる理由（ユーザー判断 2026-07-17）**: 正解が下線語の字を含むのは**語ペアそのものの構造**で、
誤答側に同じ字を混ぜると意味が変わり不可能。**公式もこの型のペアを採用している**（危ない→危険は典型）。
字の共有は弱い手がかりであり、**直せないものを無理に直すと語ペア自体を失う**。

**Bの亜種＝音の重なり**: 「みんな→皆(みな)さん」は**ルビを見れば当たる**。原因が正解側にあるので
誤答をどう作っても解消不能。語ペアごと差し替える以外にない（例: みんな→全員）。

### アプリ現行データの問題（実測 2026-07-17・93問）

- **形式が誤り**（上記）＝**93問すべて要修正**。
- **荒唐無稽ダミー**: 「この辺に新しい店があります」→ 近く ／ 誤答 **時間・天気・宿題**。**分野が全く違い、当てずっぽうで消せる**（第V部チェック2違反）。公式なら「場所の名詞」で揃える。
- **意味フィールドが揃わない**: 「美味しい」→ うまい ／ 誤答 眠い・遠い・忙しい。**い形容詞では揃っているが意味分野がバラバラ**。公式なら「味・評価の形容詞」（あまい/からい/まずい）で揃える。
- **範囲外表記**: 「**美味しい**」はN5では **おいしい** と書くのが標準。漢字表記が範囲外（第V部チェック9違反）。
- **良い実例**: 「大切」→ 大事 ／ 誤答 元気・静か・親切 ＝ **全部な形容詞**で揃う。この型は公式水準。
